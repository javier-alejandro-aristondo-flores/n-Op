# Prep — read before the talk

Background per slide — 10 slides — plus answers the script doesn't carry. Every symbol and code is named.
Reference tables at the end.

**The claim.** Finding a ground state is intractable, checking a candidate is cheap, so the system
is built around the check: physical laws compiled into a fast differentiable checker, placed inside
the loss of a neural operator that predicts crystal structure.

---

## Sigma means four things

| Written | Read as | Means |
|---|---|---|
| sigma, in a bridge record | standard deviation | uncertainty on a value |
| sigma, on the dashboard | stress | mechanical stress tensor, in kilobar |
| SIGMA, a VASP setting | smearing width | broadening on electron occupations |
| sigma-g | orbital label | bonding orbital of a diatomic |

Capital sigma is summation, and is none of the above. If asked about "the sigma," ask which.

## Slide 2 — channel completion

- **In:** a topology — which atom sits where, what bonds to what — plus whatever properties are
  known. **Out:** the channels not supplied.
- **Topology is mandatory** because partial properties alone don't determine a structure; many
  structures share them. Say "one-to-many," not "ill-posed."
- **"Channel" = function, not number.** Lattice parameter is a constant function; conductivity
  against temperature is a curve; the phonon density of states — DOS, modes per frequency — is a
  spectrum. Operators map between function spaces, which is why this isn't a multilayer perceptron
  with a wide output layer.
- Don't define "neural operator." They know.

---

## Slide 3 — why an operator

Do not define a neural operator. Argue only that this problem needs one.

| Property | Why it matters here |
|---|---|
| **Function-valued outputs** | γ̂ is a function of two spatial points; A is a function of space and time; conductivity against temperature is a curve; phonon DOS is a spectrum. A fixed-width output layer must choose a discretisation and bake it in |
| **Discretisation invariance** | supercell size and k-mesh density vary across the problem. A mesh-bound model is retrained per mesh; this one carries the same weights across meshes |
| **Evaluate at arbitrary points** | the oracle scores residuals at axis points that lie nowhere on the training grid. Interpolating after the fact is a second model with its own error |
| **Nonlocal kernels** | electronic structure is nonlocal — long-range Coulomb, collective phonon modes. An integral kernel couples the whole cell in one layer; a local stencil needs depth to move information across it |
| **Amortised solution map** | what is learned is the map from topology and partial properties to the rest of the state, not one solution. A new material is a forward pass, not a new solve |

**The load-bearing one** is evaluate-at-arbitrary-points. The corpus calls it requirement R2 and
names it the most load-bearing requirement of the seam between the oracle and the operator. If the
model could only answer on its training grid, the residual could not be scored where the physics
asks.

**Keep two axes separate if challenged.** *Architecture* — Fourier neural operator, DeepONet, graph
neural operator — is one choice. *Training regime* — supervised, then oracle-in-the-loop — is a
different one. Oracle-in-the-loop is not a property of any particular operator architecture.

## Slide 4 — the state, against a real run

### The seven slots

| Slot | Read as | Shape | What it is |
|---|---|---|---|
| `h` | "h" | 3×3 in GL⁺(3,ℝ) | the three cell vectors |
| `R_I` | "R sub I" | 3N reals | ion positions |
| `P_I` | "P sub I" | 3N reals | ion momenta |
| `Π_h` | "capital pi sub h" | 3×3 | cell momentum |
| `Z_I` | "Z sub I" | discrete integers | which element each ion is |
| `γ̂` | "gamma-hat" | operator on (r, r′) | one-body density matrix |
| `A` | "A" | field A(r, t) | external electromagnetic vector potential |

- **GL⁺(3,ℝ)** — "G-L-plus three R," the general linear group of invertible 3×3 real matrices with
  positive determinant, so the cell can't turn itself inside out. Not SL(3), determinant exactly 1,
  because volume is physical and must be free to change.
- **Parrinello–Rahman** is the method in which the cell is itself a dynamical variable with its own
  momentum, rather than a fixed box. That's what `Π_h` is.
- **`Z_I` is immutable** — no derivative runs through an integer element label, so gradient descent
  cannot search composition. Composition search is a separate outer non-gradient problem, and this
  is why there is no "proposer" component anywhere.
- **`γ̂` is a function of two spatial arguments**, r and r′, never stored dense: reciprocal-space,
  block-diagonal, low-rank in the orbital index. ~18 MB at minimum-viable-product scale against
  ~460 MB densified.
- **"2×2 in spin"** — an electron has two spin states, so the density matrix carries a 2×2 block
  (up-up, up-down, down-up, down-down) at every pair of points. Same information as the local
  magnetisation vector.
- Momenta look strange for static structure prediction. They're there for slide 5.

### Measured against one run

One real calculation: hydrogen molecule H₂ in a 10 × 10.5 × 11 ångström box. **VASP** is the Vienna
Ab initio Simulation Package, the plane-wave density-functional-theory code.

| Setting | Name | Value |
|---|---|---|
| PAW | projector augmented wave | pseudopotential scheme |
| PBE | Perdew–Burke–Ernzerhof | exchange-correlation functional |
| ENCUT | energy cutoff | 500 eV — plane-wave basis size |
| ISPIN | spin polarisation | 2, up and down treated separately |
| LNONCOLLINEAR | non-collinear magnetism | false, spins along one axis |
| IBRION | ionic-motion algorithm | 1, quasi-Newton relaxation |
| ISIF | what may move | 2, ions relax, cell fixed |

**Coverage — 3 present, 1 partial, 3 absent.**

| Slot | Status | Why |
|---|---|---|
| `h` | present | det 1155 Å³ > 0, orthorhombic, identical at all four steps (cell frozen) |
| `R_I` | present | bond relaxes 0.7414 → 0.7502 Å |
| `Z_I` | present | two hydrogens |
| `γ̂` | partial | spatial diagonal, spin structure, spectral form |
| `Π_h` | absent | ISIF 2 froze the cell |
| `P_I` | absent | IBRION 1 is relaxation, not molecular dynamics |
| `A` | absent | no such quantity in a ground-state calculation |

- **Bond length.** Experiment 0.741 Å, calculation 0.750. That's the known overestimate of GGA, the
  generalised gradient approximation family PBE belongs to. Say it before they do.
- **Three absences, three causes.** `Π_h` and `P_I` are absent by *run settings* — a different
  INCAR, the VASP input file, produces both. `A` is absent by *theory*: no ground-state calculation
  will ever carry it. `A` is what n-Op supplies itself, and it's what makes the state
  time-dependent rather than merely relaxed.
- **Conjugates plotted instead** for the two settings-absences: for `Π_h`, stress — zz swings
  +0.26 → −0.80 kilobar as the bond relaxes, xx and yy near −0.05, which is what vacuum looks like.
  For `P_I`, largest force on any ion, converging over four steps to 5.5 × 10⁻⁴ eV/Å.

**Why γ̂ is partial** — the subtlest panel:

- **CHGCAR**, the charge-density file, holds n(r) = γ(r, r), the spatial diagonal only. One number
  per grid point on a 112 × 120 × 120 grid, integrating to 2.0000 electrons, matching NELECT — the
  electron count — exactly. Full γ(r, r′) needs **WAVECAR**, the wavefunction file; this run wrote
  none.
- ISPIN 2 gives the spin diagonal, up-up and down-down. LNONCOLLINEAR false means the x and y
  magnetisation components aren't small — they're *structurally unavailable*. Net z-magnetisation
  −2 × 10⁻¹⁴ is zero to noise, correct for a closed-shell singlet where up-up and down-down each
  equal half the density.
- **The occupations are the eigenvalues of γ̂.** The spectral panel and the density panel are one
  operator in two bases. One doubly occupied sigma-g level, 8 bands at a single k-point, gap
  10.16 eV, Fermi level −9.380 eV, spin channels degenerate to under 0.6 meV.

If challenged with "you're just plotting VASP output": the target structure is fixed first and the
run measured against it, so coverage is a known property of a data source rather than something
discovered partway through training.

## Slide 5 — the GENERIC law

**GENERIC** = General Equation for the Non-Equilibrium Reversible–Irreversible Coupling. Also called
**metriplectic**, from metric + symplectic — its two brackets.

    dx/dt  =  L · δE/δx  +  M · δS/δx

Read: rate of change of the state equals L applied to the functional derivative of energy with
respect to the state, plus M applied to the functional derivative of entropy. Lower-case delta
marks a **functional** derivative — with respect to a whole function, not one variable.

| | Name | Property |
|---|---|---|
| **L** | Poisson bracket, reversible | antisymmetric, conserves energy |
| **M** | friction bracket, dissipative | symmetric positive semi-definite, produces entropy |

- **Degeneracy conditions:** L·δS/δx = 0 and M·δE/δx = 0. Reversible part makes no entropy;
  dissipative part changes no energy.
- **Why it fixes the slots.** L acts on conjugate pairs — position with momentum, cell with cell
  momentum. No `P_I`, no L on the ions; no `Π_h`, no L on the cell.
- **Regimes:** elastic = L restricted to ions and cell · phonons = L linearised about a minimum ·
  transport = M-dominated · optical = γ̂ driven by A.
- Say "restrictions of one law." Avoid "unification" — it claims more than is true.

## Slide 6 — admission gate, and uncertainty

**Fingerprint** — hash these; compare absolute energies only within one hash.

| Code | Name |
|---|---|
| functional | which exchange-correlation approximation |
| AEXX | fraction of exact exchange in a hybrid |
| HFSCREEN | screening length in a range-separated hybrid |
| ENCUT | plane-wave cutoff, i.e. basis-set size |
| POTCAR TITELs | identifying strings of the pseudopotential files |
| k-mesh | reciprocal-space sampling density |
| ISPIN | whether spin is treated |
| SIGMA | occupation smearing width |
| ISYM | whether symmetry detection was on |

Two runs at different ENCUT give a difference that looks like a physical energy and isn't — the
basis-set incompleteness error doesn't cancel between them.

**Invariant battery** — what any correct run already satisfies:

| Written | Read as | Holds because |
|---|---|---|
| Σ_I f_I = 0 | forces summed over ions vanish | translational invariance |
| σ_ij = σ_ji | stress tensor is symmetric | conservation of angular momentum |
| Σ_nk w_k f_nk = NELECT | occupations, weighted over bands and k-points, sum to the electron count | electrons are conserved |
| det(A) = V | lattice-matrix determinant equals reported volume | arithmetic |
| spin parity | odd electron count forces odd integer magnetisation | you can't pair every electron |

Closed form, one pass per frame. Catches parser bugs and run failures together — both otherwise
invisible, since the run exits cleanly and the numbers look reasonable.

**Strain, and the transpose trap.** Green–Lagrange strain E_GL, with A_ref the reference lattice
matrix, A_def the deformed one, F the deformation gradient, superscript T transpose, I the identity:

    M = A_ref⁻¹ A_def     F = Mᵀ     E_GL = ½ (FᵀF − I)

Lattice matrices are stored by **row**, so every transpose is a chance to be wrong and stay
plausible. Transpose-free, with metric tensor G = A Aᵀ:

    E_GL = ½ (A_ref⁻¹ G_def A_ref⁻ᵀ − I)

Good answer to "why does this need a computer scientist" — a row-major convention silently
corrupting a strain tensor is a software defect, not a physics one.

**Getting an uncertainty.** A bridge record is `(value, uncertainty, provenance, coverage)`; without
an uncertainty everything downstream treats the value as exact.

- **Redundancy.** Compute the same shape more than once — symmetry-equivalent configurations or
  literal repeats. Within-group spread is the numerical noise floor.
- **Symmetry nulls.** In a cubic crystal, elastic constants C₁₄, C₁₅, C₁₆ and others must vanish.
  With symmetry detection off (ISYM = 0) nothing enforced that, so whatever they come out as *is*
  accumulated error — and it exercises the whole pipeline, not just repeatability.
- **Precision, not accuracy — say it explicitly.** Basis-set incompleteness, pseudopotential error
  and functional bias are identical across equivalent configurations, cancel exactly, and
  contribute nothing to the spread. Systematic error must come from convergence testing or outside
  knowledge. Quoting a precision floor as accuracy is the likeliest thing to be caught on.

## Slide 7 — where it falls short

The honest half, and it does argumentative work: both failure modes are silent, which is the case
for scoring against something that is not learned.

- **Extrapolation.** Off the training distribution the model keeps returning in-range values with
  unchanged confidence. There is no error bar and nothing in the output marks which side of the
  support boundary a query fell on. Plain ensembles or a Gaussian-process head give calibrated
  uncertainty, but that is added machinery, not something the operator has by default.
- **Spectral bias.** Smooth, low-frequency components are learned first and sharp ones last. Band
  edges, defect levels in the gap and sharp features in the density of states are exactly the sharp
  structures, and they come out rounded. This is a well-documented property of gradient-trained
  networks, not a defect of this implementation.
- **Data appetite.** Operator learning wants dense coverage of the input distribution, which is
  why the supervised VASP epochs come first and why coverage is tracked per data source.

None of the three announces itself. A plausible number comes back either way. That is the argument
for slides 9 and 10: an independent checker whose residuals are not learned, attached during
training.

If asked whether the oracle fixes extrapolation: no. It constrains training, so the model is pushed
toward states that satisfy the laws. It is not present at inference and cannot flag an
out-of-distribution query at prediction time. Coverage metadata on the training corpus is the
honest handle on that.

## Slide 8 — the checker, and where it goes

### Why a checker

- **Barahona 1982** — ground state of a 3D Ising spin glass is **NP-hard**. NP = problems whose
  solutions are *verifiable* in polynomial time; NP-hard = at least as hard as everything in it.
- **Kitaev** — the k-local Hamiltonian problem is **QMA-complete**. QMA, Quantum Merlin–Arthur, is
  the quantum analogue of NP: quantum verifier, quantum witness. So quantum hardware doesn't rescue
  it either.
- **Baker–Gill–Solovay 1975** — oracles A and B exist with P^A = NP^A and P^B ≠ NP^B, so any proof
  technique that **relativizes** (survives handing both sides an oracle) can't settle P versus NP.
  Cite it as the limit of the oracle *technique*, not a claim about this system.
- **Decision vs valuation oracle.** Textbook: one bit, yes or no. Ours: a keyed vector of
  real-valued residuals plus **cotangents** — the gradient information for the backward pass. One
  bit gives a learner no direction; a residual with a gradient does.
- **If Grover comes up:** doesn't apply. Grover needs superposition over the search space, a
  *marking* oracle, and amplitude amplification, and only pays for unstructured search. Training
  has gradients and does local descent. The honest analogue is **CEGIS**, counterexample-guided
  inductive synthesis, with a gradient in place of the counterexample.

---

### Where it attaches

1. **Supervised epochs on VASP data** — this is what narrows the search space.
2. **Informed epoch** — oracle residuals guide final refinement.
3. **Inference** — operator alone, nothing calls the oracle.

- **Why not residuals first?** A residual is a local signal; over a large space there's nothing for
  it to point toward. The oracle refines an already-narrowed space, it doesn't search.
- **Keyed residuals** — one per law, per axis point, never summed. Allows individual weighting,
  scheduling, and auditing which law fired. Also what makes the acceptance test meaningful: perturb
  a structure and the key that fires names the violated law.

## Slide 9 — the residual categories

Nineteen total; six on screen.

| Category | Condition | Read as |
|---|---|---|
| Structural | ∇_R E_BO = 0 | gradient of the Born–Oppenheimer energy (electrons solved with nuclei fixed) with respect to ion positions vanishes — the structure is force-free. Plus stress consistent with the cell |
| Positivity | ω² ≥ 0 | squared phonon frequencies non-negative on anything claimed stable; a negative one is an imaginary frequency, meaning the structure falls apart along that mode |
| Positivity | γ̂ = γ̂†, 0 ⪯ γ̂ ⪯ 1, Tr γ̂ = N_e | density matrix equals its conjugate transpose (Hermitian, dagger); eigenvalues between zero and one, since an orbital can't be less than empty or more than full; trace is the electron count |
| Conservation | ∂ρ/∂t + ∇·j = 0 | rate of change of charge density rho plus divergence of current density j is zero — charge neither appears nor vanishes. Plus energy |
| Algebraic | Σ_R Φ(R) = 0 | acoustic sum rule: force-constant matrix Phi summed over lattice vectors vanishes, so translating the whole crystal costs nothing |
| Algebraic | D = μ k_B T / q | Einstein relation: diffusivity = mobility mu × Boltzmann constant × temperature ÷ charge |
| Thermodynamic | — | temperature–pressure convex hull with a metastability band, so metastable diamond scores zero instead of being penalised for not being graphite |
| Symmetry | — | space-group equivariance: symmetry applied to the input applies to the output |

**Why the complete state is required.** The trace condition and phonon positivity aren't computable
from atom positions. That's why the operator hands over every slot, not just a geometry.

## Backup — the compiler

- **Stages.** Symbolic lift and applicability pruning → symmetry quotient → invariant synthesis →
  algebraic simplification → lowering, adjoint synthesis, code generation → runtime kernel.
- **Closed vocabulary.** 3 inputs, a 7-tuple state, 132 substantive formulas, 12 methods, 20
  templates, 11 observable bundles, 19 residual categories, 10 certificate obligations.
- **Guards must be first-order decidable.** "Is diamond polar?" is false, so polar-optical
  scattering is pruned before code generation. An undecidable guard is rejected at registration,
  not at runtime.
- **Futamura.** First projection: specialising an interpreter to a fixed program yields a compiled
  program. Here, specialising the general physics evaluator to one material yields that material's
  kernel. Compile in seconds, call in microseconds.
- **Refusal is absence.** An unsupported check isn't a zero or an error code — it isn't in the
  compiled kernel, and its key is absent from every output map, so it can't come back wrong.
- **Runtime.** No per-sample hot path worse than order log n, none calls a solver. Gradients through
  a converged fixed point use the **implicit function theorem** — one linear solve — rather than
  taping every iteration and differentiating through it.

## Questions to expect

- **Isn't this just a PINN?** A physics-informed neural network adds a hand-written penalty term.
  This compiles a closed, citation-traced vocabulary into a content-addressed artifact, keeps every
  residual separately addressable, and refuses what it can't stand behind. The difference is the
  provenance and refusal machinery, not the form of the loss.
- **Results?** None. No code yet, everything quoted is a design target. Say it on slide 8 unprompted.
- **How do you know the residuals are right?** Each is a registry row with a literature citation and
  a stated validity boundary, against a standing register of 51 documented traps — sign conventions,
  unit systems, reference frames — checked before anything touching them lands.
- **Why not just run more DFT?** Cost at device conditions. And more of the same data saturates; the
  useful question is whether the error curve has flattened, which is cheap to test.
- **Time evolution?** Researched, verdict "survives with restrictions." Not claimed; own wave.
- **Which language?** Open. A polyglot proposal exists and everything named in it is a candidate.
- **Does it design materials?** No. Inverse design is out of scope for the oracle, which scores
  complete candidate states, owns no loop, and proposes nothing.
- **Topological materials?** Two different Kitaev results get conflated. The talk's is *local
  Hamiltonian is QMA-complete*, pure complexity theory. Band topology is separate. The corpus does
  carry a **topology atlas** computed per composition at compose time: space group; **AZ class**,
  Altland–Zirnbauer, the tenfold classification of Hamiltonians by time-reversal, particle-hole and
  chiral symmetry — Kitaev's periodic table is the K-theory derivation of that same classification;
  the symmetry-indicator group; **EBRs**, elementary band representations; compatibility relations.
  Global integral invariants — **Chern numbers**, the **Z₂ invariant** via a Pfaffian, **Wilson
  loops** — are opt-in per observable, not core catalog. It classifies a structure handed to it and
  generates nothing. Computing indicators also needs irreducible-representation labels off the
  wavefunctions plus **SOC**, spin–orbit coupling; this corpus ran ISYM = 0 with no SOC, so they
  aren't computable from it at all.
- **What can't it do?** Strongly correlated systems — γ̂ is mean-field by construction, so Mott
  insulators and spin liquids are out. Hole transport in beta-gallium-oxide — holes self-trap as
  small polarons, so there's no band-like positive-carrier transport to model. Breakdown above
  ~500 °C — the hot-carrier anchors don't exist in the literature. Each is recorded as a refusal
  with a stated reason.

## Don't say

- "Proposer." No such component.
- The oracle as a permanent loop around the operator, or any oracle call at inference.
- The precision floor as an accuracy figure.
- That the implementation language is decided.
- GENERIC as a "unification." The regimes are restrictions of it.
