The metrics

QuantityPrimary metricWhy that one
densitiesrelative L2, per runthe standard in the literature
localization fieldmean absolute error, with a three-dimensional structural similarity beside itA deliberate deviation: relative L2's denominator changes with each cell's low-localization volume, so the same local accuracy would score differently in different campaigns.
local potentialrelative L2 after removing each field's meana periodic cell has no absolute zero of potential
density of statescurve L1: the integrated absolute difference over the truth's own integral; the one-dimensional Wasserstein distance beside itcompares curves, not points

A secondary metric splits the error into low and high Fourier bands.

Found It is not a true per-band relative error. On a test field the same error scores √2 differently when it lies along z instead of x (0.030861 against 0.021822). Over a band covering the whole field it returns 0.296828 where plain relative L2 gives 0.298005.

From runs to one number

Each run gets its error; each unit gets the median of its runs; the result is the median over units. Symmetry copies inside one orbit therefore count once. Weighting by runs would let crowded, easy orbits outvote sparse, hard ones; on the branch–trunk task, aggregating to orbits moved the ridge floor from 0.251% to 0.414%. The interval printed beside a median is a bootstrap over units, but of the mean, not the median, a mislabel the grading deep dive found.

The pass rule

One line of code decides every verdict: improvement = 1 − member ÷ floor. The model passes if its improvement meets the required margin and is killed otherwise. A negative improvement means the floor did better.

Worked example from the perovskite lattice task: a member at 0.0183 against a ridge floor at 0.0423 with a 25% bar has improvement 1 − 0.0183 ÷ 0.0423 = 56.7%, so it passes. The manifold decoder at 0.002452 against bracketing interpolation at 0.000911 has improvement −169.2% against a required 33.3%, so it is killed.

Where the verdicts live

  • Each model's report.md, written by its report.py: the source of truth.
  • results.json: the same rows and verdicts in machine form. Seven models write one; the flagship and the branch–trunk network do not.
  • cross_member.md: one table built from the results.json files, so the flagship has no row on its own task.
  • operator-results.md: the one-page index, kept by hand. Its own words say every number is copied from a report. Its test checks only four rows and passes even when it checks none.
