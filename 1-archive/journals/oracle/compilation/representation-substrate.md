# The representation substrate

Every load-bearing object in the oracle — vocabularies, registered generators, selected
subsets, sparse coverage masks, sidecars, evidence, symbolic forms, applicability
predicates, the physics graph itself — is expressed as a fiber of **one substrate**,
parameterized by typed indexed universes, content-addressed Merkle DAGs, and a small
family of op signatures.

## A contract, not a container

The substrate is a **contract**, not a single dynamic container. Each cluster keeps the
backend that wins on its own hot path; what the substrate unifies is their identity,
serialization and attachment disciplines. Reading it as one universal container is the
error to avoid — nothing here asks a Roaring bitmap and a hash-consed tensor DAG to
share a representation, only to share an identity rule.

## Substrate primitives

Five primitives. Every other representation is a fiber over them.

```
Address[D] = Hash(domain_separator(D), schema_version(D), canonical_node_bytes)

Universe[U] = {
  id              : Address[Universe],
  carrier_kind    : Closed | Open | Derived,
  element_type    : TypeId,
  enumerator?     : (Universe[U]) → Iterator<Element[U]>,
  ordinal_policy  : DenseU32 | DenseU64 | None,
  schema_version  : Nat,
  backend_policy  : (density_estimate) → BackendChoice
}

SparseSet[U] = {
  universe : Universe[U],
  backend  : Tuple | Bitset | Roaring | HAMT | RankSelect,
  root     : Address[Set[U]],
  members  : (backend-specific canonical layout)
}

PersistentMap[K, V] = {
  key_universe?  : Universe[K],
  value_domain   : DomainId,
  backend        : HAMT(branching=32) | MerkleTrie,
  root           : Address[Map[K, V]]
}

MerkleDAG[S, L] = {
  domain         : DomainId,
  signature      : S,                       -- op-signature parameter
  leaf_type      : L,
  node_store     : Map<Address, Node[S, L]>,
  root           : Address[DAG[S, L]]
}

Node[S, L] = Leaf(L) | Op(op : S.Op, attrs : S.Attrs[op], children : S.Arities[op])
```

`Address[D]` is **domain-separated**: two values from different domains never collide
even with identical canonical bytes. The digest is SHA-256, 256 bits wide, truncated
nowhere in storage — truncation is allowed only in log output.

Two constant factors are worth naming, because they are what the asymptotics below
actually cost. An `Address` comparison is a 32-byte compare, roughly two wide vector
loads. A `Universe` ordinal is a machine word that **doubles as a dense array index**,
so membership and array addressing are the same operation rather than two.

## The op-signature family

Four op signatures parameterize the Merkle DAG instances in the oracle. Three cover
the general expression DAGs:

- **`PredicateOps`** — reduced ordered binary decision diagram operations over typed
  parameterized atoms drawn from a closed vocabulary. Atom order is part of the
  predicate vocabulary's version. Used by [applicability-classifiers#predicate-storage].
- **`SymbolicTensorOps`** — a colored operad, equivalently a free symmetric monoidal
  category, generated by the target shapes of [coupling-structure#target-shapes] — scalar,
  antisymmetric form, positive-semidefinite symmetric form — plus tensor product,
  contraction, derivative, group action, projection and binding. Composition is
  operadic substitution. Used by `InvariantTerm` and `FormulaApply`.
- **`EvidenceOps`** — attestation, aggregation by semilattice meet, reference linkage,
  trajectory chunk. Used by [cert-obligations#evidence-aggregation].

The fourth, **`GroupOps`** — multiplication, inversion, restriction,
antipode and time-reversal twist, character, projector — describes the finite-quotient
algebra of `CrystalSymmetryGroup`. Its derived outputs (irrep tables, Fourier
projectors, zone stalks) are stored as ordinary substrate fibers.

## What each cluster is made of

| Cluster | Shape | Backend / signature |
|---|---|---|
| **vocabularies** — `StateComponent`, `SubDofTag`, `IrrepLabel`, `OutputRole`, `NodeKind`, `InputKind`, `CategoryTag`, `AxisLabel`, `BundleId`, `Layer0Type` | `Universe[T]` instances with dense ordinals | closed universes get `DenseU32`; open universes get `DenseU64` with an append-only registry |
| **registered-generators** — `FormulaRecord`, `ResidualGenerator`, `CouplingChannel` | `Element[RegistryUniverse[k]]` | kind-indexed dispatch; payload canonicalized by the serialization rule |
| **sidecars** — the per-stage sidecars of [physics-graph#sidecars] | `PersistentMap[TypedKey, EvidenceBearing[V]]` | HAMT, branching 32; stage-visible |
| **evidence** — the attestation DAG: `Witness`, `OneShotCert`, `IterativeResult`, the obligation outputs | `MerkleDAG[EvidenceOps, EvidencePayload]` | persistent attestation DAG |
| **content-addressing** — `ContentAddress`, `ResidualKey`, generator hashes, cache keys, sidecar fingerprints | `Address[D]` | SHA-256, domain-separated |
| **selected-subsets** — `CouplingSpec`, active residual, formula and bundle subsets | `SparseSet[RegistryUniverse]` in a Boolean lattice | HAMT or Roaring; subset identity is the root |
| **sparse-masks** — coverage masks, axis sets, subgraph node sets, irrep-block indices | `SparseSet[Universe]` | chosen from the universe's density estimate |

Four fibers are named directly rather than by cluster:

| Fiber | Shape | Backend / signature |
|---|---|---|
| `InvariantTerm` and `FormulaApply` symbolic form — **a separate fiber, not part of the evidence cluster** | `MerkleDAG[SymbolicTensorOps, TypedLeaf]` | hash-consed tensor-algebra DAG |
| applicability predicates | `MerkleDAG[PredicateOps, VocabularyAtom]` | versioned decision diagram over vocabulary atoms |
| `CrystalSymmetryGroup` | graded composite atlas, sui generis, plus derived `MerkleDAG[GroupOps, …]` caches | see [canonical-vocabularies#scope] |
| `PhysicsGraph` | closure of the output address multiset under children-pointers | identity is the multiset of output-root addresses ([physics-graph#node]) |

The symbolic-form row shares a backend family with the evidence cluster and shares
nothing else: different op signature, different leaf type, different lifetime. It is
its own fiber, and reading it as evidence would put tensor algebra inside the
attestation DAG.

## The canonical serialization rule

One rule, used everywhere an `Address[D]` is computed.

1. **Domain separator first** — a fixed 16-byte tag for the domain, so identical bytes
   in different domains cannot collide.
2. **Schema version next** — an unsigned 32-bit value declared in the universe
   descriptor, bumped on incompatible changes.
3. **Records** — named fields sorted lexicographically by field name; each field
   serialized as its name bytes followed by its length-prefixed value bytes.
4. **Sequences** — length-prefixed by an unsigned 64-bit element count; elements in
   declared order.
5. **Sets** — elements canonicalized individually, sorted by address bytes, then
   length-prefixed and concatenated, so order cannot leak into identity.
6. **Maps** — entries canonicalized as key bytes and value bytes, sorted by key bytes,
   length-prefixed.
7. **Sum types** — discriminator drawn from the vocabulary indexing the sum, serialized
   as a 32-bit ordinal followed by a length-prefixed payload.
8. **Continuous-factor data** — U(1) charge sectors serialize as signed integer lattice
   weights with a basis-id tag; SU(2) sectors as doubled spin labels plus the address
   of the Clebsch–Gordan table version.
9. **Group action laws** — normalized homomorphism and twist generators over layer ids;
   relation rows sorted by domain, codomain and action label.
10. **Optional values** — `None` is a single `0x00` byte, `Some(v)` is `0x01` followed
    by length-prefixed value bytes. A present-but-empty field and an absent field hash
    distinctly.
11. **Scalar leaves** — `Nat` and `Int` as fixed-width big-endian; `Float` as IEEE-754
    binary64 big-endian with two normalizations applied first: every not-a-number maps
    to one canonical quiet pattern, and negative zero maps to positive zero. Rule 8
    covers only the U(1) and SU(2) sector weights; arbitrary model floats use this rule.

**Why rules 10 and 11 read the way they do.** The float normalization of rule 11 is
what makes content addressing safe for *computed* values: without it, a sign of zero or
a distinct not-a-number bit pattern would fork the identity of two numerically equal
results. Length-prefixing rather than delimiters is what prevents concatenation
ambiguity, so two different field sequences cannot serialize to the same bytes. Hashing
is the only payload-linear operation anywhere on the identity path; everything
downstream of it is a constant-time address compare.

The serializer's **injectivity** is the single highest-consequence invariant in the
system: two distinct values hashing equal would break every cache, every dedup and
every equality test at once.

Every cache keyed on an address consumes this rule unchanged — the reference cache
([cert-obligations#reference-cache]) is the worked instance.

## Identity is exact; the error bar rides alongside

**Normative.** `Address` equality is **exact**. No tolerance, no quantization, no
rounding before hashing. Every object in the substrate also carries an error bar —
`Quantity.combineTol` ([residual-definitions#error-budget]) composes one along the DAG — and that
error bar is carried **beside** the address, never inside it.

This is not conservatism. It is forced, and the reason is algebraic.

Address equality `≡` is an **equivalence relation**: reflexive, symmetric, *transitive*.
The natural relation on numerical objects is

```
a ≈_ε b  ⟺  ‖a − b‖ ≤ ε
```

which is reflexive and symmetric but **not transitive** — `‖a−b‖ ≤ ε` and `‖b−c‖ ≤ ε`
give only `‖a−c‖ ≤ 2ε`. A relation of that kind, a *tolerance relation*, does not
induce a partition. It induces a **covering by maximal cliques**, which is not a
quotient and is NP-hard to compute. Everything the substrate is built from needs the
quotient:

- **No equivalence classes means no canonical representative, which means nothing to
  hash.** The serialization rule exists to make one byte string per value; a covering
  offers a *set* of candidate representatives, and choosing among them changes every
  value downstream.
- **Hash-consing and Merkle dedup die.** Two subtrees equal to within a tolerance have
  different addresses and will not dedup; forcing them to share picks a representative
  arbitrarily.
- **Constant-time address equality dies**, and the hot-path commitments below go with
  it.
- **Union-find dies**, and e-classes die with it — which is the machinery the
  rewrite-admission rule stands on ([compose-time-pipeline#rewrite-admission]).

So the substrate needs a quotient and the mathematics offers only a covering. The
resolution is to stop asking for the quotient: the tolerance relation is never used as
an identity relation, so its non-transitivity never has to be repaired.

**The e-graph community arrived at the same separation independently.** In the sound
rewriting architecture that the rewrite-admission rule adopts
([compose-time-pipeline#rewrite-admission]), the equality relation stays exact over the
reals and the interval facts ride *alongside* it as an e-class analysis. Two
communities reaching the same split from different directions is the strongest evidence
available that it is the right one.

**Rejected alternatives**, recorded so they are not re-proposed:

- **Quantized addressing** — round to a grid, then hash. Buys tolerance-dedup at the
  cost of the serializer's injectivity, the highest-consequence invariant in the
  system, and still picks an arbitrary representative, now with a grid artifact at
  every cell boundary.
- **Ball or interval addressing** — the address names a ball rather than a point.
  Sound, but it relocates the non-transitivity into "what happens when two balls partly
  overlap" rather than dissolving it, and it doubles every payload.

## Estimate, don't decide

Because the tolerance cannot live in the address, it has to live somewhere. It lives in
evidence:

> **Any operation that can make the computed object differ from its exact counterpart
> emits a computable *a-posteriori* estimate of that difference, as certification
> evidence.**

The registration obligation this creates is stated at
[residual-machinery#fidelity-generators]; the
estimates enter the error budget through `Quantity.combineTol` exactly as every other
term does ([residual-definitions#error-budget]). Three properties make the obligation cheap rather
than burdensome.

- **Nothing branches at runtime.** The kernel computes *a number*. Computing a number
  is not structural branching, so the always-cheap discipline
  ([compose-time-pipeline#always-cheap]) is untouched.
- **Nothing is refused for being approximate.** The discrepancy is *scored* and the
  consumer decides — the project's own thesis ([product#score-not-solve]: score, don't
  solve; [product#evidence-not-verdict]: evidence, never verdicts) applied to the oracle's own numerics rather than only to the physics.
- **The gate is weaker than an exactness gate, not stronger.** "The operation must be
  able to estimate its own error" admits strictly more than "the operation must be
  exact."

Every estimator required so far is a byproduct of work already done. A truncated
singular value decomposition already computes the discarded singular values, so the
spectral-norm error is the first discarded one exactly. A truncated inner solve already
computes its stopping residual.

## Hot-path commitments

No **runtime per-sample** hot path is worse than logarithmic. No hot path requires a
solver call. No hot path requires duplicate serialization. The two super-logarithmic
rows below — symmetry projector, evidence aggregation — are compile-time, cached, or
certification-side, and are not per-sample.

| Op | Asymptotic | Constant factor |
|---|---|---|
| `Address` equality | `O(1)` | one 32-byte compare, about two wide vector loads |
| `Universe` member equality | `O(1)` | one machine-word compare on the dense handle |
| `SparseSet` membership (Roaring) | `O(log n)` | container probe |
| `SparseSet` membership (HAMT) | `O(log₃₂ n)` | path walk |
| `SparseSet` membership (tuple, n ≤ 8) | `O(n)` | linear scan, no indirection |
| `PersistentMap` lookup | `O(log₃₂ n)` | one HAMT walk |
| `PersistentMap` insert at stage exit | `O(log₃₂ n)` | path copy |
| `MerkleDAG` root equality | `O(1)` | one address compare |
| `MerkleDAG` diff | `O(changed frontier)` | equal subtrees skipped on one address compare |
| decision-diagram evaluate | `O(decision-path length)` | three-pointer fetch per node |
| decision-diagram equivalence or subsumption | `O(1)` after canonicalization | memoized apply |
| `EvidenceOps` aggregate verdict | `O(children)` | semilattice meet, early exit on failure |
| group element multiplication | `O(1)` average | Schreier–Sims product table |
| symmetry projector evaluation | `O(\|G\|/\|H\| · tensor rank)` | cached as an `Address` after first evaluation |

The HAMT bound is concrete: depth is at most `⌈log₃₂ |keys|⌉`, which is about six for a
billion keys, and an insert path-copies exactly one root-to-leaf path, leaving the rest
shared. That is what makes stage-to-stage sidecar versioning cheap enough to do at
every stage exit.

Backend selection for `SparseSet`:

- `n ≤ 8` → sorted tuple, a free-monoid backend with no allocation cost.
- dense `n ≤ 256` over a small closed universe → bitset, with word-parallel union and
  intersection.
- sparse over a large universe → Roaring, which compresses runs and has vectorized bulk
  operations.
- persistent and diffable → HAMT or Merkle trie.

Universe descriptors carry the threshold ladder. **The choice is a property of the
universe, fixed at registration — not of an individual sparse set.**

## What the substrate replaces

- **Per-cluster identity disciplines.** `ContentAddress`, `ResidualKey`, generator
  hashes, residual cache keys, sidecar fingerprints and reference-row keys are all
  `Address[D]`. There is one canonical serialization rule, not per-cluster conventions.
- **Ad-hoc sidecar storage.** Sidecars are typed `PersistentMap` fibers. Cross-stage
  visibility is the **stage-visibility order** — symbolic lift, symmetry quotient,
  invariant synthesis, algebraic simplification, lowering and adjoint synthesis,
  runtime kernel application ([compose-time-pipeline#boundary]) — under which a sidecar
  produced by one stage is visible to every later stage and to none earlier. Cache
  eligibility is a per-domain flag: ephemeral, audit-only, or cache-eligible. Evidence
  is **attached** by identifier, never duplicated into a sidecar payload.
- **Three separate Merkle infrastructures.** Symbolic forms, applicability decision
  diagrams and the evidence attestation DAG share one `MerkleDAG[S, L]` substrate, each
  with its own op signature.
- **The physics graph as a special object.** The graph is the closure of its output
  addresses under children-pointers, and its identity rule is stated once, at
  [physics-graph#node]. Edges are not separately identified: the argument-list addresses
  inside a node payload *are* the edges.

## What the substrate does not replace

- **`CrystalSymmetryGroup` stays sui generis at the algebra layer.** Its *identity* is
  an `Address[GroupAtlas]` and its *derived outputs* are substrate fibers, but its
  multiplication, projector and restriction semantics are not reduced to the substrate.
  Hopf-algebra and Fourier views are derived view layers over the group defined in
  [canonical-vocabularies#scope].
- **Certification checkers are not decision diagrams.** They are typed registered
  morphisms from artifacts to evidence. Applicability predicates are first-order
  decidable; certification checkers evaluate whole dynamical artifacts
  ([generic-dynamics#generic-form]). Both register through the registered-generators cluster, and
  the split between them is preserved.
- **The operadic structure on `SymbolicTensorOps` is an explanation, not a carrier.**
  The colored operad is the algebraic account of the op signature; the storage carrier
  is the hash-consed Merkle DAG.

## Versioning discipline

Every universe and every domain carries a `schema_version`. Incompatible changes bump
it. Old `Address` values remain valid identifiers **of the old schema**; they are never
silently reinterpreted under the new one. Migration between schema versions is an
explicit registered morphism, never an implicit decode-with-new-rules.

Decision-diagram atom orders are versioned per predicate vocabulary in the same way.
Adding an atom creates a new order id; predicate roots built under one order are
comparable only under that order, with explicit re-canonicalization at migration
boundaries.

The typed state slots ([unified-state#slots]) and the seam schema
([pino-bridge#surface]) are both
versioned by this rule, so a schema bump on either side is visible as an address change
rather than as a silent reinterpretation.
