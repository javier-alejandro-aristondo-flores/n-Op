## Key Findings

1. **The safe/provable split is the right architecture.** Component A changes only the SCF *starting point*, so the fixed point (the exact DFT answer) is untouched — it is safe by construction. Component B changes the *in-loop update operator*, which is where speed lives but also where correctness is at risk; wrapping it in a safeguard makes correctness **independent of the neural network's Lipschitz constant**, because the classical fallback carries the convergence guarantee.

2. **The empirical precedent is real but the net-time trap is real too.** ChargE3Net (npj Comput. Mater. 10:161, 2024) demonstrably cuts SCF steps (median **15→11**, i.e. **26.7%**, on unseen Materials Project data; **14→10**, i.e. **28.6%**, on GNoME; ~**96%** of runs used fewer steps than superposition-of-atomic-densities). But the 2026 ELECTRAFI study (arXiv:2601.19966, ICML 2026) shows only ~75–80% of step reductions convert to wall-time savings and that **"ChargE3Net does not reduce the net computation time on MP in any domain"** because its inference cost is too high. This is why Component A must be a *tiny* fixed-grid FNO and must report inference cost honestly.

3. **The theorem's scaffolding is fully in place in the literature.** Global convergence under nonexpansiveness (Zhang–O'Donoghue–Boyd 2020), local r-linear rate of Anderson (Toth–Kelley 2015), the AA rate-improvement mechanism (Evans–Pollock–Rebholz–Xiao 2020), the plug-and-play insertion principle (Ryu et al. 2019), and guaranteed a posteriori KS bounds (Cancès/Herbst/Levitt/Dusson/Stamm) each discharge a specific proof obligation. The one **load-bearing open assumption** is nonexpansiveness/contraction of the SCF map for **metals under smearing** — the safeguard preserves the *warranty* regardless, so only the *local-rate claim* narrows if it fails.

4. **DFTK exposes exactly the interfaces this needs.** A custom mixing is a struct implementing `DFTK.mix_density(mixing, basis, δF; kwargs...)` where the input `δF = ρ_out − ρ_in` and the return value `δρ` is added to `ρ_in` — literally the residual-field-to-density-update map, i.e. the inverse-Jacobian object. Per-iteration `(ρin, ρout)` are available via the `callback=` interface for harvesting training data. GPU support (SCF and forces, NVIDIA + AMD, NC pseudopotentials) is **stable as of December 2025**. **Hard limitation:** DFTK supports libxc LDA/GGA/meta-GGA only — **no hybrids/exact exchange** (HSE06 out of scope in-platform).

5. **The corpus feeds three cleanly separated roles**, and PAW-vs-NC incompatibility forces a strict validation rule: **never compare raw densities or absolute energies** between VASP (PAW) and DFTK (norm-conserving) — only band gaps, relative energies, and equation-of-state parameters.

6. **The inspection suite is the instrument for this program's own open questions, and the physics makes it unusually cheap.** O5 — the load-bearing open assumption — currently has no measurement anywhere in the design; an Arnoldi spectrum of the linearized update operator against the unit circle (F-B10) supplies one. OQ4 (does Anderson on a learned preconditioner double-count) is answered by logging the angle between the two proposed steps, which costs one extra preconditioner application and **zero extra KS solves**. OQ3 is answered by plotting the certificate against the true error. And because Component B's classical baseline is *already* a scalar function of |G|, "what did the network learn?" has a canonical answer format — a transfer function overlaid on the Kerker curve — in a basis the FNO's weights already live in. Inspection here is not instrumentation bolted onto physics; it is the physics, read back out.

## Details

### Section 1 — Mission and Product Definition

**What "SCF" means (plain language).** Density Functional Theory (DFT) computes the electronic structure of matter from the electron density. In Kohn–Sham (KS) DFT you guess a density ρ, build an effective potential V[ρ], solve a quantum eigenvalue problem to get a new density ρ_new, and repeat until ρ stops changing. That loop is the **self-consistent field (SCF)** iteration — a fixed-point iteration ρ → V[ρ] → eigenproblem → ρ_new. When it converges slowly or diverges, whole calculations become expensive or impossible.

**Component A ("VASP-facing initializer").** A small neural operator mapping (atomic geometry of a periodic cell) → (converged electron charge density on the FFT grid). It writes its prediction as a CHGCAR file that VASP reads (ICHARG=1) as the SCF starting guess. Because it changes only the starting point, never the fixed-point map, the converged answer is bit-for-bit the standard DFT answer; only the iteration count changes. The "safe by construction" component.

**Component B ("DFTK safeguarded learned mixer").** A learned approximation to the inverse SCF-Jacobian (inverse dielectric operator) acting as the charge-mixing preconditioner inside the SCF loop, replacing/augmenting the classical Kerker preconditioner. It is wrapped in a **safeguard**: accept the learned step only if the SCF residual norm decreases by a preset factor θ < 1; otherwise fall back to a classical Kerker-preconditioned Anderson/Pulay step. The "provably safe" component.

**Honest paper↔program relationship (REQUIRED framing).** The paper's central contribution is Component B's **theorem** (global convergence + local-rate improvement + per-iterate certificates). The program is the artifact that instantiates and validates the theorem, plus Component A as a pragmatic, independently shippable deliverable. Component A has no theorem beyond exactness-by-construction; it stands on measured wall-time. The paper must state this plainly.

**What ships.** (1) A DFTK mixer package exposing a learned preconditioner with a proven worst-case warranty (never worse than the safeguarded classical fallback) plus per-iterate certificates; (2) a VASP-facing initializer utility. Each ships only if it clears its pre-registered gate (Sections 6–9).

**Crowding status (carry forward).** Learned in-loop SCF mixing *with a convergence theorem* is unclaimed as of August 2026. Adjacent claimed work is all empirical without proofs: ChargE3Net/DeepSCF/density-matrix initializers (initialization only); NeuralSCF (surrogate solver, not preconditioner); HamEvo (DEQ-flavored, no proofs); Generative Latent Space Dynamics (notes FNO drift). Classical incumbents to beat/compare: Kerker; LDOS mixing; low-rank dielectric-matrix (LRDM) preconditioner; elliptic preconditioner.

### Section 2 — Physics Foundations for the CS Reader

**2.1 What KS-DFT solves.** The many-electron Schrödinger equation is intractable because the wavefunction depends on all electron coordinates at once. **Kohn–Sham DFT** (Kohn & Sham, Phys. Rev. 140, A1133, 1965) replaces the interacting system with a fictitious system of *non-interacting* electrons having the *same density*. The price is one unknown term, the **exchange–correlation (XC) functional**, packaging all many-body effects the non-interacting picture omits. Core objects: the **electron density ρ(r)** (a scalar field on a 3-D grid, the fixed-point variable); the **KS potential V[ρ]** = external (nuclei/pseudopotentials) + Hartree (classical electron repulsion, from Poisson's equation) + XC; and the **KS eigenproblem** Ĥ[ρ]ψ_i = ε_i ψ_i, from which ρ_new = Σ f_i |ψ_i|² with occupations f_i.

**2.2 The SCF loop as a fixed point.** Define the **KS density map** F: ρ_in ↦ ρ_out (Song & Feng call this F_KS). Self-consistency = finding ρ★ = F(ρ★), the ground-state density. The naive iteration usually diverges, so one **mixes**: ρ_{n+1} = ρ_n + α P⁻¹ (F(ρ_n) − ρ_n), where α is the **damping/mixing parameter**, P⁻¹ the **preconditioner**, and (F(ρ_n) − ρ_n) the **residual** (the SCF residual field, driven to zero).

**2.3 Plane waves, cutoffs, FFT grids, k-points, Brillouin zone.** Crystals are periodic, so orbitals expand in **plane waves** e^{iG·r}. The **energy cutoff** E_cut keeps |G|²/2 ≤ E_cut (more cutoff = more accuracy and cost). The density lives on a real-space **FFT grid** (roughly twice as fine as the wavefunction grid per direction); the defect data uses 80×80×80 throughout. Periodicity labels states by crystal momentum **k** in the **Brillouin zone** (BZ); observables are BZ integrals approximated on a finite **k-point mesh** (e.g. Γ-centred 7×7×7 → 172 irreducible points in the strain data).

**2.4 Pseudopotentials: PAW vs norm-conserving (and why the densities are not comparable).** A **pseudopotential** freezes chemically inert core electrons and replaces the nuclear Coulomb singularity with a smooth effective potential, so far fewer plane waves are needed. **Norm-conserving (NC-PSP)** is the simplest rigorous scheme; DFTK uses NC-PSPs (Kleinman–Bylander form), with the recommended modern family **PseudoDojo** (van Setten et al., Comput. Phys. Commun. 226, 39, 2018) — per that paper, *"our final set contains 141 pseudopotentials split into a standard and a stringent accuracy table"* (85-element table, ~70,000 test calculations), read by DFTK in UPF/GTH formats. **PAW (projector augmented wave)** is VASP's default; it stores a *pseudo* valence density plus one-centre corrections inside augmentation spheres. **The raw grid density from PAW is not the same object as the NC all-pseudo-valence density** — hence the program never compares raw densities or absolute energies across the two codes.

**2.5 Occupations, smearing, metals vs insulators.** An **insulator/semiconductor** has a **band gap** (occupied and empty states cleanly separated; occupations 0 or 1). A **metal** has bands crossing the **Fermi level**, so occupations jump discontinuously as states cross, wrecking BZ-integral convergence and destabilizing the SCF. The fix is **smearing**: a smooth occupation of width σ (a fictitious electronic temperature). DFTK offers **Fermi–Dirac**, **Gaussian**, **Methfessel–Paxton** (higher-order; occupations can go negative/non-monotonic), and **Marzari–Vanderbilt "cold"** (positive-definite). Smearing is what makes the SCF Jacobian well-defined for metals.

**2.6 Why SCF diverges: charge sloshing, the dielectric/Jacobian picture, Kerker.** The SCF map's local behavior is governed by its **Jacobian** ≈ the **dielectric operator** ε† = 1 − χ₀K, where χ₀ is the independent-particle susceptibility and K the Hartree+XC kernel. Convergence rate is set by the **condition number** κ = λ_max/λ_min; large κ ⇒ slow. **Charge sloshing (mechanical picture):** the Coulomb kernel behaves like 1/|G|² at long wavelength (small G), so a tiny long-wavelength density error produces a huge potential error, over-corrected next iteration into an equally large opposite error — charge "sloshes" and grows. Worst in large cells, in vacuum/slab/cluster geometries, and in metals (large χ₀ near the Fermi level). **Kerker preconditioning** (Kerker, Phys. Rev. B **23**, 3082, 1981 — note volume 23, not 24) inverts the Thomas–Fermi dielectric model: 𝒦(G) = |G|²/(|G|² + λ²), operator form −Δ/(1−Δ). It is a **high-pass filter** damping the dangerous small-G updates while leaving short wavelengths alone; ideal for bulk metals, but not adaptive to inhomogeneity (which LDOS mixing fixes).

**2.7 Fractional occupations and degenerate levels — a distinct pathology.** Separate from sloshing: symmetry-degenerate, partially-filled defect levels can converge to symmetry-constrained fractional occupations, oscillate between occupation patterns, or land in the wrong state. Different mathematics (derivative discontinuity / near-degeneracy at the Fermi level, not the long-wavelength Coulomb divergence). In this corpus, 12–14 "mag-quarter" configs converged to fractional occupations at exactly ±0.25 μB, plus 33 odd-electron/zero-magnetization runs — these geometries become **Component B's diamond pain-case suite** (geometries only; their VASP densities are not B's training data).

**2.8 Canonical iteration counts (orientation; re-measure, never trust blind).** Easy bulk insulator/semiconductor with a good preconditioner: well under ~20 iterations. Bulk metal with poor damping: dozens of iterations or failure; with matched Kerker/LDOS it drops sharply and becomes nearly size-independent. Large inhomogeneous systems (metal slabs, metal/insulator interfaces): simple schemes may not converge in 50 iterations, whereas LDOS mixing keeps κ nearly flat as the system grows (Herbst & Levitt 2021). **REQUIRED:** record exact per-system baseline counts before any model work.

### Section 3 — Mathematical Foundations (the theorem's scaffolding)

**3.1 Fixed-point theory.** *Contraction / Banach:* if ‖G(x)−G(y)‖ ≤ c‖x−y‖ with c < 1, there is a unique fixed point and the iteration converges at least linearly with rate c (target regime for insulators). *Nonexpansiveness:* c ≤ 1; alone it does not give convergence, but it is the minimal assumption for the Zhang–O'Donoghue–Boyd safeguard. *Local vs global:* global = converges from a wide set of starts; local = only when already close. *Rate:* **q-linear** = ‖e_{n+1}‖ ≤ c‖e_n‖ each step; **r-linear** = error bounded by a q-linear sequence (weaker, "eventually linear"). Toth–Kelley's Anderson result is r-linear.

**3.2 Anderson acceleration = multisecant quasi-Newton; equivalence to Pulay/DIIS.** **Anderson acceleration (AA)** (Anderson, J. ACM 12(4):547–560, 1965) combines the last m+1 residuals to extrapolate a better next iterate; it is a **multisecant quasi-Newton** method implicitly building an approximate inverse Jacobian from iterate history. In electronic structure the same algorithm was independently invented by **Pulay** as **DIIS** (Pulay, Chem. Phys. Lett. 73, 393–398, 1980; J. Comput. Chem. 3, 556–560, 1982). **Walker & Ni (SIAM J. Numer. Anal. 49, 1715, 2011)** established the modern AA/DIIS equivalence and the GMRES connection (optimal damping, unlimited depth, linear problem). **Depth m** = number of past iterates retained. **SCF-specific theory:** Cancès & Le Bris (ESAIM: M2AN 34, 749, 2000) analyzed SCF/level-shifting/optimal-damping; **Cancès, Kemlin & Levitt (SIAM J. Matrix Anal. Appl. 42, 243–274, 2021)** give asymptotic rates for damped SCF vs direct minimization and their spectral-gap dependence — the bar Component B must beat locally.

**3.3 The safeguard template (Zhang–O'Donoghue–Boyd, SIAM J. Optim. 30(4):3170–3197, 2020).** First **globally convergent** Type-I Anderson variant assuming **only nonexpansiveness**. Three transplanted ingredients: (1) **safeguarding** — accept an accelerated (learned) step only if it passes a sufficient-decrease test on the residual norm, else take a safe step; (2) **Powell-type regularization** — keep the quasi-Newton update matrix bounded/well-conditioned; (3) **restart / strong-linear-independence check** — discard history when stored differences become nearly dependent. This is the exact skeleton for Component B's global-convergence claim.

**3.4 Plug-and-play (PnP) conditions — what the learned operator must satisfy.** **Ryu et al. (ICML 2019)** proved PnP-FBS/ADMM converge without diminishing step size if the denoiser satisfies a Lipschitz/residual condition (residual operator nonexpansive/contractive), enforced in training via **real spectral normalization**. Lesson: a learned operator can live inside a convergent iteration if either (a) it satisfies a controllable Lipschitz/nonexpansiveness condition, or (b) it is wrapped in a safeguard that requires no such property. **This program chooses route (b) as primary** (correctness independent of the network's Lipschitz constant) and treats route (a) — Lipschitz-controlled training — as an optional local-rate enhancement. Follow-ups: Hurault et al. (ICML 2022, gradient-step/proximal denoisers); Pesquet et al. (SIAM J. Imaging Sci. 14(3):1206, 2021, maximally-monotone operators).

**3.5 A posteriori bounds: the certificate machinery.** An **a posteriori** bound is computed after an approximate solution, from the residual, and bounds the true error of *this* result (vs an **a priori** asymptotic bound). *Kato–Temple inequality* (Kato, *Perturbation Theory for Linear Operators*, Springer): for a Hermitian operator with approximate eigenpair (θ, x), residual r = Âx − θx, and a computable spectral gap, gives a **guaranteed two-sided** eigenvalue bound in terms of ‖r‖ and the gap (weak point: you must know the gap). *Bauer–Fike:* eigenvalue error ≤ ‖r‖ for Hermitian/normal matrices — cheaper, assumption-light, looser. *Plane-wave KS bounds:* Herbst, Levitt & Cancès (Faraday Discuss. 224, 227, 2020; non-self-consistent KS, DFTK reference implementation); **Cancès, Dusson, Kemlin & Levitt (SIAM J. Sci. Comput. 44, B1312–B1340, 2022; guaranteed bounds for *properties*)**; Dusson & Maday (J. Comput. Phys. 491, 112352, 2023; perturbation post-processing); **Bordignon, Dusson, Cancès, Kemlin, Lainez Reyes & Stamm (arXiv:2409.11769; SIAM J. Sci. Comput. 47(5):A2881–A2905, 2025; fully guaranteed computable energy bounds** for periodic KS with convex functionals). *Guaranteed vs asymptotic:* the Bordignon et al. energy bound and Kato–Temple are guaranteed given their hypotheses; several property bounds are guaranteed under stated gap/regularity assumptions; perturbation post-processing is asymptotic unless paired with a guaranteed remainder.

**3.6 THE TARGET THEOREM (north star).** *Informal:* Run the safeguarded learned-mixer on the DFTK SCF for a system in scope: propose the learned update; accept iff the preconditioned residual norm decreases by ≥ factor θ < 1; else take a Kerker-preconditioned Anderson step. Then **(i) [GLOBAL]** the iterates converge from the standard initialization; **(ii) [LOCAL]** if the learned map approximates the true inverse SCF-Jacobian within ε, the asymptotic linear factor is no worse than, and generically strictly better than, Kerker–Anderson; **(iii) [CERTIFICATE]** each accepted iterate carries a computable a posteriori bound on the target observable(s) from one extra residual evaluation.

### Section 4 — Complete Nomenclature / Glossary

**DFT / electronic structure.** **DFT** — density functional theory. **KS-DFT** — the practical DFT mapping the interacting system to non-interacting electrons of the same density. **SCF** — the self-consistent fixed-point iteration. **ρ(r)** — electron density, scalar field on the FFT grid, the fixed-point variable. **XC functional** — encodes many-body effects; rungs: **LDA** (local density), **GGA** (adds gradient; PBE is standard), **meta-GGA** (adds kinetic-energy density), **hybrid** (mixes exact exchange; e.g. HSE06 with α=0.27). DFTK supports LDA/GGA/meta-GGA via libxc only. **Exact exchange** — Hartree–Fock-like non-local exchange in hybrids; not in DFTK. **Band gap** — energy gap between highest occupied and lowest unoccupied states; zero for metals. **Fermi level** — energy dividing occupied from empty states. **Smearing** — smooth occupation of width σ for metals (Fermi–Dirac, Gaussian, Methfessel–Paxton, Marzari–Vanderbilt). **PAW** — VASP's pseudopotential scheme (pseudo+augmentation densities). **NC-PSP** — norm-conserving pseudopotential (DFTK; PseudoDojo family). **VASP files:** **INCAR** (parameters), **POSCAR** (geometry), **KPOINTS** (k-mesh), **POTCAR** (pseudopotential; **licensed** — must never leave the private data volume), **CHGCAR** (density × cell volume on the FFT grid + PAW one-centre occupancies), **WAVECAR** (wavefunctions). **ICHARG** — initial-density tag: 1 = read CHGCAR, 2 = superposition of atomic densities (SAD, default), +10 = fixed density (non-SCF). **NELM** — max SCF steps. **EDIFF** — SCF energy convergence threshold. **ISPIN** — 1 non-spin-polarized, 2 spin-polarized. **Magnetization** — spin-up minus spin-down. **LMAXMIX** — l-detail of PAW occupancies written to CHGCAR (matters on restart).

**Numerical analysis.** **Fixed point** — x with G(x)=x. **Residual** — r = F(ρ)−ρ (driven to zero). **Preconditioner P⁻¹** — applied to the residual to improve conditioning; ideally ≈ inverse Jacobian. **Jacobian** — derivative of the residual map; here ≈ ε† = 1 − χ₀K. **Spectral radius / condition number κ** — largest eigenvalue magnitude / λ_max/λ_min. **Contraction factor c** — Lipschitz constant < 1. **Quasi-Newton / multisecant** — approximate (inverse) Jacobian from history. **DIIS/Pulay** — chemistry name for Anderson-type residual extrapolation. **Anderson depth m** — past iterates kept. **Damping α** — step-size scaling. **Trust region / line search** — restrict/scale a step to guarantee progress (DFTK has adaptive damping line search). **Safeguard** — acceptance test reverting to a safe step on failure. **a posteriori vs a priori** — computed-from-residual bound on the actual result vs pre-computation asymptotic bound.

**Operator learning.** **Neural operator** — network approximating a map between function spaces (here residual field → density update), designed to be **discretization-independent**. **FNO** — Fourier neural operator; parameterizes its integral kernel in Fourier space; **modes** = retained Fourier modes (truncation/regularization knob); naturally periodic. **DeepONet** — **branch** net (input function) × **trunk** net (query location). **Discretization independence** — evaluable on grids/resolutions unseen in training; the load-bearing property for a multi-cell-size preconditioner. **Residual field** — the SCF residual as a function on the cell (operator input). **Periodic boundary** — fields wrap around the cell (FNO respects this).

**Project-specific.** **Component A / B** — VASP initializer / DFTK safeguarded learned mixer. **Pain suite / pain case** — hard SCF benchmarks (Al slab, metal/insulator interface, iron near magnetism, plus corpus mag-quarter geometries). **Iterate logging** — recording per-SCF-step densities/residuals via DFTK callbacks. **Certificate** — per-iterate guaranteed a posteriori error bound on the learned prediction. **Warranty** — the proven worst-case guarantee (never worse than the fallback). **Gate** — a pre-registered go/no-go with kill/proceed thresholds fixed in advance. **Noise floor** — measured baseline variability (wall-time scatter, or trivial-model NMAE) against which every residual/improvement is quoted. **Ship-either-way** — a negative result is a valid, publishable outcome. **NMAE** — normalized mean absolute error (density-prediction accuracy; ChargE3Net-class ≈ 0.5%).

**Inspection (§8).** **Inspection suite** — the pre-registered set of record schemas, tabular artifacts (T1–T5) and figures (F-*) that evidences every gate decision. **Run manifest** — one record per run carrying all provenance (code versions, hardware, physics and solver config, seeds); everything joins on its `run_id`. **Iterate record** — one record per SCF step: residual norms, radial |G| power bands, occupations, the safeguard block, the certificate block, and timings. **Field snapshot** — the heavy grid arrays (ρ_in, ρ_out, residual, δρ), written only at `full` logging tier. **Model card** — one record per trained operator, including the FNO spectral kernel dump. **Prediction record** — one record per Component A held-out configuration (Component A has no SCF iterates of its own). **Log level** — `off` / `standard` / `full`; gate timings are always measured at `off`. **Transfer function ĝ(|G|)** — the learned preconditioner's impulse response as a function of wavevector magnitude, the object directly comparable to the Kerker curve; a *linearization* of a nonlinear operator, never the operator itself. **Clearance class** — whether an artifact may leave the private data volume (error/difference fields yes, raw run payloads no). **Safeguard event** — a rejected learned step; a free, in-distribution, labelled failure case. **Provenance stamp** — the `run_id`/`model_id`/`schema_version` footer every figure carries; an unstamped figure is not evidence. **Headroom floor** — the warm-start iteration count from the converged density, the lower bound drawn on convergence plots.

### Section 5 — The Annotated Reading List

**(a) SCF convergence & mixing classics.**
- *Kerker, Phys. Rev. B 23, 3082 (1981)* — Thomas–Fermi-based high-pass preconditioner suppressing long-wavelength charge sloshing in metals. The classical object Component B learns a better version of.
- *Pulay, Chem. Phys. Lett. 73, 393 (1980); J. Comput. Chem. 3, 556 (1982)* — DIIS residual-extrapolation mixing; the chemistry-side invention of Anderson acceleration. Incumbent accelerator.
- *Anderson, J. ACM 12(4):547 (1965)* — original acceleration of fixed-point iterations; numerical-analysis root of DIIS.
- *Broyden (Math. Comp., 1965)* — classic quasi-Newton root-finder; ancestor of multisecant mixing.
- *Kresse & Furthmüller, Phys. Rev. B 54, 11169 (1996); Comput. Mater. Sci. 6, 15 (1996)* — VASP's plane-wave/PAW methodology and mixing scheme; the baseline Component A accelerates.
- *Lin & Yang, SIAM J. Sci. Comput. (2013)* — elliptic (Poisson-like) preconditioner; principled alternative to Kerker.
- *Herbst & Levitt, J. Phys.: Condens. Matter 33, 085503 (2021)* — LDOS-based, parameter-free, black-box preconditioner adapting to metal/insulator/vacuum inhomogeneity; **DFTK's default mixing**; strongest classical baseline for Component B.
- *Das & Gavini, Phys. Rev. B 107, 125133 (2023)* — low-rank dielectric-matrix (LRDM) preconditioner (explicitly computed approximate inverse Jacobian via Gâteaux derivatives). Per the paper, benchmark systems from ~100 to 1100 atoms (~500–20,000 electrons) all *"converge robustly within 20–30 iterations"* with up to 3.4× cost reduction. Conceptually the exact object Component B learns.
- *Woods, Payne & Hasnip, J. Phys.: Condens. Matter 31, 453001 (2019)* — best modern review of computing the SCF in KS-DFT: failure modes, mixing/preconditioning, and the SCF-x_n benchmark suite. Primary orientation reference.

**(b) Anderson/DIIS theory.**

### Section 6 — Program Design, Component A (VASP-facing initializer)

**Goal.** Predict the converged charge density for a diamond-defect geometry and hand it to VASP as the SCF starting guess via CHGCAR, cutting SCF iterations and — the real target — **net wall-clock time**.

**6.1 Data contract.** Source: the ~84 GB VASP diamond corpus; Component A trains on the **substitutional point-defect study** — 64-atom diamond supercell (a=3.567 Å reference; 7.157335 Å cell), ~199 runs / ~140 configurations, CHGCAR grids verified 80×80×80, ISPIN=2 throughout. **CHGCAR parsing (REQUIRED):** CHGCAR stores **charge density × cell volume (ρ·V)** on the fine FFT grid, written **x-fastest, z-slowest**. For **ISPIN=2** the file has **two grid blocks** — first the **total** density (up+down), then the **magnetization** density (up−down) — followed by PAW one-centre occupancies (not needed for a grid-only NC guess). The pipeline divides by cell volume to recover ρ and reconstructs the two spin channels from (total, magnetization). **Dedup/exclusions (REQUIRED):** exclude the corrupt Zr HSE06 run (byte-identical PBE copy); train/deploy **PBE-to-PBE first (RECOMMENDED)**; flag or exclude the 33 odd-electron and 12–14 mag-quarter runs (primarily B's concern). **Licensing guard (REQUIRED):** assertion-based guards ensure no raw run content or POTCAR data leaves the private data volume; only numeric aggregates and the trained model are committed. **Refinement for inspection (§8.1, rule I2):** "numeric aggregates" is widened — deliberately and narrowly — to admit grid-resolved **error and difference** fields and their visualizations, without which F-A2/F-A3 cannot exist at all. A difference between a prediction and a reference carries no POTCAR content and does not publish the reference; raw CHGCAR/WAVECAR payloads and verbatim run directories remain barred. The clearance classes of I2 are the operative list, and the same assertion guards enforce them.

**6.2 The geometry→density model.** **Architecture (RECOMMENDED):** a deliberately **tiny FNO** on the fixed 80³ periodic grid. Rationale: the ELECTRAFI net-time analysis (arXiv:2601.19966) shows inference cost can wipe out step savings — verbatim, *"ChargE3Net does not reduce the net computation time on MP in any domain, while for GNoME, there is a slight average saving for system sizes above 30 atoms."* A small fixed-grid FNO has near-negligible inference cost. **Input encoding (RECOMMENDED):** smeared atomic-density channels (place each atom's species-dependent Gaussian/atomic density on the grid — essentially SAD as an input feature), so the network learns the *correction* from SAD to converged density (mirroring DeepSCF's δρ target). **Parameter budget (REQUIRED discipline):** only ~140 configurations, but each supplies dense per-voxel supervision (80³ ≈ 5.1×10⁵ voxels) — large supervision per sample, tiny geometry diversity. Keep parameters small (few FNO modes); validate on held-out configurations/dopants, not held-out voxels.

**6.3 Two pre-registered floors (REQUIRED, fixed before training).** (1) **1-D local-density lookup** mapping local PBE density → correction, which on the user's diamond data reaches **0.52–0.65% NMAE** — ChargE3Net-class (published 0.523%). Component A must beat this on held-out configs. (2) **Superposition of atomic densities (SAD)** — VASP's native ICHARG=2 default and the reference every step-reduction is measured against.

**6.4 Deployment path (VERIFY-confirmed).** Write the predicted density (× volume, correct spin blocks, x-fastest) as a **CHGCAR**; run VASP with **ICHARG=1** (read CHGCAR as SCF starting guess). Fixed point untouched ⇒ converged answer exactly the standard DFT answer; only iteration count changes. **Spin (REQUIRED):** ISPIN=2 CHGCAR must carry both total and magnetization blocks; a wrong/missing magnetization block mis-initializes the spin density and can *increase* iterations. **PAW-restart caveat (OPEN):** a grid-only written density omits PAW one-centre occupancies; VASP re-derives them during SCF so correctness is preserved, but quantify whether omission hurts step savings and set LMAXMIX appropriately.

**6.5 Evaluation protocol (REQUIRED).** Accuracy: NMAE on held-out configurations (held-out dopants/geometries, not voxels). Speed: both **SCF-step reduction** and **net wall-clock time** on **real VASP reruns** of held-out configs (predicted CHGCAR vs SAD), with **model inference cost reported and subtracted** (ELECTRAFI discipline: only ~75–80% of step reductions convert to wall-time, and inference can flip net savings negative). Quote wall-time next to measured run-to-run scatter on identical inputs (noise floor). **Evidence (REQUIRED):** accuracy on **F-A1**; step reduction on **F-A10** (paired scatter against SAD, directly comparable to ChargE3Net's 15→11 / 14→10); net time on **F-A11** against the **F-P1** noise floor. **F-A5** and **F-A6** are required alongside them because NMAE alone does not distinguish the error modes: a model can post an excellent aggregate score while leaving exactly the long-wavelength error that costs SCF steps, and only the planar-averaged profile and the radial spectrum separate that from cosmetic high-frequency error.

**6.6 Kill/ship (pre-registered).** **Ship** iff Component A (a) beats the 1-D lookup floor on held-out NMAE **and** (b) yields positive net wall-time on real reruns after charging inference cost. **Kill** if either fails; report the negative result at full force. **Evidence (REQUIRED, per rule I3):** clause (a) is decided by **F-A1** against **T3**; clause (b) by **F-A11** against **F-P1**. No ship/kill call is made without both figures and the `run_id`s they consumed.

**6.7 Inspection artifacts and figures (REQUIRED).** Component A emits the §8.2 prediction/rerun record (type 5) for every held-out configuration, and produces **T3** plus **F-A1**–**F-A12** per §8.4. Two of these are load-bearing beyond ordinary diligence. **F-A3/F-A4** exist because §6.4 warns that a wrong or missing magnetization block mis-initializes the spin density and can *increase* iterations — F-A4 tests that warning directly rather than assuming it. **F-A12** exists because the CHGCAR contract of §6.1 (ρ·V scaling, x-fastest ordering, two blocks under ISPIN=2) is fiddly enough that a silent index transposition is Component A's most likely *invisible* failure: it would degrade the initializer while leaving every accuracy metric intact. Timing figures are produced from runs at `log_level=off` per rule I1.

### Section 7 — Program Design, Component B (DFTK safeguarded learned mixer)

**Goal.** A learned preconditioner (approximate inverse SCF-Jacobian) inside DFTK's SCF, wrapped in a safeguard that inherits global convergence and is designed to beat Kerker–Anderson locally, with a per-iterate certificate.

**7.1 DFTK integration (VERIFY-confirmed interfaces).** **Custom mixing (REQUIRED mechanism):** DFTK exposes `mixing=` on `self_consistent_field`; a custom mixing is a struct implementing `DFTK.mix_density(mixing, basis, δF; kwargs...)`. **Crucial interface fact:** the input `δF = ρ_out − ρ_in` and `mix_density` **returns δρ**, which DFTK adds to `ρ_in` to form the next density — so the learned operator is literally δF ↦ δρ (residual field → density update), the inverse-Jacobian object. `kwargs` include `n_iter`, enabling "simple mixing for first k steps, then learned" schedules (as in DFTK's own `MyMixing` example). **Where the safeguard sits (REQUIRED):** DFTK layers **Anderson on top of mixing**. Two options: **(B1, RECOMMENDED)** implement the learned preconditioner as the mixing, let DFTK's Anderson run on top, and implement the **safeguard as a custom solver/acceptance wrapper** that checks the residual-decrease test and, on failure, recomputes with `KerkerMixing` (DFTK lets you call `DFTK.mix_density(KerkerMixing(), basis, δF; kwargs...)` directly inside your own mixing); **(B2)** implement the whole safeguarded-Anderson loop as a custom `solver=` routine (more faithful to Zhang–O'Donoghue–Boyd's Powell regularization/restart, more code). **Iterate-logging callback (REQUIRED for training data):** DFTK's SCF accepts `callback=` receiving a named tuple with `ρin`, `ρout`, energies, and iteration index each step (and once after convergence); a custom callback (pattern: `ScfDefaultCallback`, `ScfSaveCheckpoints`) logs `(ρin, ρout)` → residual fields, and with converged `ρ★` the targets. Note: a custom `callback` silences the default convergence table. The callback records the §8.2 iterate-record fields, not an ad-hoc subset. **Convergence criterion:** default is ‖Δρ‖ < `tol`; use it for apples-to-apples baselines. **Driving DFTK from Python (REQUIRED note):** the program runs DFTK through juliacall, so a small Julia shim defines the mixing struct and the learned forward pass is a Python callback invoked from inside Julia's SCF loop, with `δF` crossing the boundary every iteration. That marshaling cost sits on the **production** path, not the instrumentation path, and is therefore reported separately from logging overhead (§7.6, rule I1). Pin the shim alongside the DFTK version under R5.

**7.2 Training-data generation.** **Free trajectory data (REQUIRED):** re-solve the **1131 distinct strain geometries** (2-atom primitive cells, seconds each, Γ-centred 7×7×7 → 172 irreducible k-points) in DFTK **with iterate logging**, harvesting `(residual field → ideal update)` pairs along each trajectory. **Augmentation (REQUIRED):** vary E_cut and FFT-grid size so the operator learns a resolution-independent map (Kovachki et al. 2023). **Defining the "ideal update" target (OPEN — central design question):** input is δF; target is the update the true inverse Jacobian would give. Options: (1) **converged-density difference** δρ* = ρ★ − ρ_in (trivially available; but teaches "jump to the answer," surrogate-solver flavor); (2) **finite-difference dielectric probe** estimating ε†⁻¹δF via Gâteaux derivatives à la Das–Gavini (teaches the genuine inverse-Jacobian action, best for O3; costlier, noisier); (3) **hybrid** — train on (1) for a cheap prior, fine-tune on (2) near convergence. **RECOMMENDED:** start with (1) to derisk, move to (2) where the O3 local-rate claim is demonstrated. Log as OPEN-QUESTION #1. **Harvest evidence (REQUIRED):** the harvest emits **F-D1** (pair census by SCF-iteration index and residual-norm decile, with the evaluation distribution overlaid) and **F-D2** (coverage map over `Ecut`, grid, cell size and σ, training points against evaluation points). F-D1 exists because harvesting along converged trajectories oversamples easy near-converged residuals by construction — a model trained mostly on those looks excellent in validation and is useless in the iterations that actually cost time. F-D2 makes the extrapolation gap in §7.3's discretization-independence claim visible rather than assumed.

**7.3 Operator architecture constraints.** **Small FNO on periodic grids (RECOMMENDED):** periodic-by-construction matches the cell; few modes = regularization against the **FNO drift on density fields** (arXiv:2509.00169). The safeguard is the backstop against drift; keeping the operator small reduces how often it must fire. **Discretization independence is REQUIRED:** the same trained operator must precondition 2-atom strain cells (training) and larger pain-case cells (evaluation).

**7.4 Safeguard implementation (from Zhang–O'Donoghue–Boyd).** **Acceptance test (REQUIRED):** accept the learned step iff the preconditioned residual norm decreases by ≥ factor **θ < 1**; else fall back to Kerker-preconditioned Anderson. **Powell-type regularization (REQUIRED):** keep the update operator bounded/well-conditioned. **Restart check (REQUIRED):** monitor strong linear independence of stored differences; restart when it degrades. **θ (OPEN):** fixed vs adaptive — OPEN-QUESTION #2.

**7.5 Theorem section plan.** State the theorem and assumptions as in §3.6; declare the system class for which nonexpansiveness/contraction is proved / assumed / empirically checked — **metals under smearing are the danger zone (O5)**. **Warranty vs local-rate separation (REQUIRED framing):** O1 gives the unconditional warranty (never worse than fallback); O3 gives the local-rate improvement on the subclass where the ε-approximation holds. If O5 fails for some metals, the warranty still holds; only the local-rate claim narrows.

**7.6 Certificate implementation.** **Which bound:** Kato–Temple / Bauer–Fike for the Hermitian eigenpairs; Cancès–Dusson–Kemlin–Levitt (2022) / Bordignon et al. (2025) for energy/property certificates. **Computed from what:** one extra residual evaluation per accepted iterate (residual already available; the eigenvalue gap for Kato–Temple comes from the diagonalization). **Cost (REQUIRED to report):** target O(1) extra residual evaluations; quote overhead as a fraction of an SCF step, and report it separately from both logging overhead and the juliacall marshaling cost of §7.1 (rule I1). **Logged per iterate:** certificate type, value, cost, and `hypotheses_ok` with the specific hypothesis that failed — this is what **F-B9** is built from. **OPEN:** whether certificates stay *guaranteed* under smearing/fractional occupations (the bounds assume a spectral gap that smeared metals blur) — OPEN-QUESTION #3.

**7.7 Evaluation suite.** **Standard pain cases (REQUIRED baselines first):** aluminium slab (sloshing/vacuum), metal/insulator interface (e.g. the GaAs+SiO₂ / Al+vacuum systems of Herbst–Levitt 2021), iron near magnetic transitions. Record baseline counts for SimpleMixing, KerkerMixing, DielectricMixing, and **LdosMixing (DFTK default)**. **Corpus-derived pain cases (REQUIRED):** the diamond **mag-quarter** (±0.25 μB) and odd-electron geometries. **Headroom probe (REQUIRED):** iteration count from the *converged* density (warm-start lower bound) vs from scratch; the gap is the maximum achievable speedup. **Kill Component B on a case if headroom < 1.5×** — evidenced by **F-B12** with the kill line drawn. **Metric:** iterations and wall-time to fixed `tol`, learned mixer vs LdosMixing/Kerker–Anderson, with safeguard-firing rate reported. **Evidence (REQUIRED, per rule I3):** the ship/kill call rests on **F-B7** (both panels — iterations *and* wall-time, since step wins need not be time wins) against the **T5** baselines; safeguard behaviour on **F-B4**/**F-B5**; certificate validity on **F-B9**; and the two claims that would otherwise go unchecked on **F-B10** (O5, empirically) and **F-B11** (discretization independence). Baseline and comparison timings are measured at `log_level=off`.

**7.8 Cross-code ground-truth validation.** Converge **one 64-atom defect configuration** in DFTK (NC-PSP, PseudoDojo) and compare **band gap and relative energies** vs the VASP (PAW) endpoint within a **pre-stated tolerance**. **Never** compare raw densities or absolute energies. **REQUIRED caveat:** state the expected PAW-vs-NC delta for carbon/diamond from PseudoDojo benchmarks and set the tolerance accordingly; agreement within tolerance validates the DFTK setup as a workload generator. **Evidence:** **F-X1** (allowed observables only, tolerance band drawn) and **F-X2**. The prohibition on raw-density and absolute-energy comparison is encoded in the figure spec itself (§8.5), not left to reviewer discipline.

**7.9 Inspection artifacts and figures (REQUIRED).** Component B emits the §8.2 iterate record (type 2) every SCF step and the model card (type 4) per trained operator, and produces **T1**, **T2**, **T4**, **T5** plus **F-B1**–**F-B12** per §8.4. Four carry weight beyond diagnostics. **F-B1** is the "what did it learn" figure and is only meaningful with the §8.7 linearization caveat attached. **F-B4/T4** turn the safeguard into an instrument: every rejected step is a labelled failure case, generated free, in-distribution, at exactly the moment the operator is wrong. **F-B10** is the only thing in this program that measures **O5**, the central risk of §7.5. **F-B11** is what makes §7.3's REQUIRED discretization independence falsifiable rather than merely asserted. Per rule I1, per-iteration records are `standard`-tier scalars; field snapshots are `full`-tier and taken at pre-registered iterations plus every rejected step.

### Section 8 — Inspectability, Instrumentation, and Visualization

**Purpose and status.** This section is **research infrastructure, not a scientific claim.** It adds no theorem, asserts no new result, and constrains no architecture. It exists because this program's culture — pre-registered gates, measured noise floors, negative results reported at full force (§10) — is only cashable if the machinery to look inside a run exists *before* the result does. A negative result you cannot explain is not a publishable negative result.

Inspection here operates at the same three epistemic tiers the rest of this document uses. **Proved:** the a posteriori certificate (§7.6) — a guaranteed bound on an actual iterate. **Demonstrated:** measured spectral probes, transfer functions, and calibration plots — empirical, honest about their hypotheses. **Descriptive:** error maps and trajectory plots — they show, they do not establish. Every artifact below is labelled by which tier it belongs to, and nothing in this section is ever cited as proof.

One structural piece of luck is worth naming, because it is why this is cheap. Component B learns an approximate inverse dielectric operator, and the classical object it replaces is *literally a scalar function of one variable* — Kerker's 𝒦(G) = |G|²/(|G|²+λ²). "What did the network learn?" therefore has a canonical answer format that already exists in this field's vocabulary, and the FNO's weights already live in the basis that answer is written in. Most interpretability work is hard because there is nothing to explain *into*. Here there is.

**8.1 Three cross-cutting rules.**

**I1 — Logging tiers (REQUIRED).** Every run declares `log_level ∈ {off, standard, full}`. **`off`** — the production and timing path; zero inspection I/O. **`standard`** — run manifest plus per-iteration scalar records; no field payloads. **`full`** — adds field snapshots at pre-registered iterations, plus **every rejected step unconditionally** (rejections are the scarce and valuable events; never sample them).

**REQUIRED:** every gate timing number (§6.5, §6.6, §7.7) is measured at `off`, and the `off → standard → full` overhead is measured once per platform and reported beside it. Without this rule the inspection requirement silently sabotages Component A's ship gate, which *is* a wall-time measurement.

**REQUIRED — reduce-then-marshal.** With DFTK driven from Python (§7.1), every array crossing the juliacall boundary costs. All reductions — norms, radial |G| bins, cosine angles — are computed on whichever side already holds the array; only scalars cross at `standard`. State honestly in cost accounting that `δF` already crosses the boundary every iteration on the *production* path, because the learned forward pass lives in Python: that cost belongs to the integration choice, not to instrumentation, and §7.6 reports the two separately.

**I2 — Clearance classes (REQUIRED).** Inspection collides with the licensing firewall of §6.1/§10: every useful figure is derived from raw run content. Resolve it explicitly rather than case by case. **Cleared to leave the private volume:** derived scalar and tabular aggregates; grid-resolved **error and difference** fields and their visualizations; transfer functions, spectra, and radial bin data; trained model weights; iteration, timing, and safeguard records. **Not cleared:** raw POTCAR content or any quantity from which it is recoverable; raw CHGCAR/WAVECAR payloads; verbatim run directories. Every record and every figure carries a `clearance_class`, and the assertion guards §10 already mandates gate the export path.

**I3 — No gate decision without its artifact (REQUIRED).** Every gate clause in §6.6, §7.7 and §9.1 names the artifact and figure IDs that evidence it, and cites the `run_id`s consumed. The artifact and figure lists of §8.3–§8.4 are **pre-registered before any training**, exactly like the acceptance thresholds, so post-hoc figure selection is structurally impossible rather than merely discouraged.

**Notebook anti-rot rule (REQUIRED).** The stable contract is the *record schema*, not the analysis code. Notebooks are parameterized by `run_id`, re-runnable from logs alone with no hidden state; any notebook cited in a gate decision is committed with outputs, and the `run_id`s it consumed are recorded in the commit.

**8.2 Record schemas.** Concrete fields are fixed here; serialization format is deliberately not (**RECOMMENDED:** a language-neutral columnar/array format readable from both Python and Julia). All records carry `schema_version`; the schema is versioned and breaking changes are migrations, not edits. Six record types.

**(1) Run manifest** — one per run. `run_id`; `created_utc`; `component ∈ {A,B}`; `purpose ∈ {baseline, training-harvest, benchmark, ablation, probe, gate-evidence}`; `log_level`; `clearance_class`; `reference_run_id` — the converged or baseline run this one is paired against, null if unpaired. *Provenance:* `git_commit` + dirty flag; versions of DFTK, Julia, Python, juliacall, torch, numpy, libxc; `data_snapshot_id`; RNG seeds (numpy, torch, Julia). *Hardware:* host, CPU model, thread counts, BLAS threads, GPU model or null. *Physics config:* `system_id`, formula, `n_atoms`, lattice (3×3), positions hash, functional, pseudopotential family and per-species files, `Ecut`, `fft_grid`, `kgrid` and `n_irreducible_k`, smearing type and σ, spin polarization, symmetries used. *Solver config:* mixing name and parameters (including Kerker λ), solver, Anderson depth m, `tol`, `maxiter`, damping α, safeguard θ, initial-density source ∈ {SAD, CHGCAR, model, converged}. *Model provenance:* `model_id`, `training_run_id`. *Outcome:* `converged`, `n_iterations`, `final_residual`, `wall_time_total`, `wall_time_instrumentation`. — *`reference_run_id` is load-bearing and easy to omit: F-B9 needs a converged reference to compute true error against, F-B12 pairs from-scratch against warm-start runs, and Component A's rerun comparison pairs SAD against model initialization. Without an explicit pairing field those joins get reconstructed by naming convention, which is how paired comparisons silently become unpaired ones.*

**(2) Iterate record** — one per SCF step; the heart of the schema. `run_id`, `iter`. *Residual:* `residual_norm` (the norm DFTK's own convergence check uses, so baselines stay apples-to-apples), `preconditioned_residual_norm` (the quantity the safeguard actually tests), `residual_power_by_G_band` (K fixed radial bins, **pre-registered edges**). *Energetics:* total energy plus DFTK's component breakdown, `energy_change`. *Spectrum and occupations:* `fermi_level`, `band_gap`, `n_bands`, `min_gap_at_fermi` (required by Kato–Temple, §3.5), min and max fractional occupation, total and per-spin magnetization — the last serving the mag-quarter pathology of §2.7 directly.

*Safeguard block (Component B).* `step_source ∈ {learned, fallback-kerker-anderson, simple, warmup}`; `proposed_residual_norm`; `theta`; `theta_margin` (how close the call was, not merely which way it went); `accepted`; `rejection_reason ∈ {residual-increase, non-finite, powell-regularization, restart-triggered, nan-guard}`; `anderson_depth_active`; `restart_fired`; `powell_regularization_applied`; `history_condition_number` — log the *number* from the strong-linear-independence check of §3.3/§7.4, not just the boolean; `norm(δρ_learned)`, `norm(δρ_fallback)`, `cos_angle(δρ_learned, δρ_fallback)`, `cos_angle(δρ_learned, δρ_anderson)`.

> **Why the two cosine angles are nearly free (REQUIRED to exploit).** §7.1 establishes that `DFTK.mix_density(KerkerMixing(), basis, δF)` may be called directly inside a custom mixing, and that `mix_density` performs **no diagonalization**. Both proposed updates on the *identical* residual therefore cost one extra preconditioner application and **zero extra KS solves**. What is *not* cheap is the residual the classical step *would have produced* — that requires a full F evaluation, i.e. a full diagonalization. Hence: comparing proposed steps as fields is cheap and logged every iteration; comparing outcomes requires paired full trajectories from identical starts, which is F-B7 and is run deliberately, not continuously.

*Certificate block.* `certificate_type ∈ {kato-temple, bauer-fike, energy-bound}`; `certificate_value`; `hypotheses_ok` plus which hypothesis failed (a gap too small under smearing is the expected failure — OQ3); `certificate_cost_seconds`. *Timing:* `wall_time_iter`, `_diagonalization`, `_mix`, `_model_forward`, `_logging`, `_ffi_marshal`. *Payload pointers* (at `full` only): references to stored fields, never inline.

**(3) Field snapshot** — the heavy arrays; written at `full` only, at pre-registered iterations plus every rejected step. `ρ_in`, `ρ_out`, the residual field, `δρ_learned`, `δρ_fallback`, per spin channel. **REQUIRED:** each snapshot stores its grid, lattice and units, so that a figure can be made from it without re-deriving physics from elsewhere.

**(4) Model card** — one per trained model. `model_id` (hash of weights); architecture config (FNO width, modes per axis, layers, activation, lifting/projection dims) and parameter count; training provenance (dataset snapshot, **split definition — held-out configurations and dopants per §6.2, never held-out voxels**, number of training pairs, loss, optimizer, epochs, seeds); the **spectral kernel dump** (the FNO R(k) tensors, or at minimum per-mode Frobenius norms — this is what makes the weights inspectable at all); and the eval summary against both §6.3 floors.

**(5) Prediction / rerun record** — one per Component A held-out configuration. *Component A has no SCF iterates of its own, so without this record none of its figures are derivable from the schema.* `config_id`, `model_id`, `split ∈ {train, val, test}`, dopant species, `run_id` of the reference VASP run. *Accuracy:* `nmae_total`, `nmae_magnetization`, `nmae_by_G_band[]`, `nmae_by_species{}`, `nmae_vs_distance_from_defect[]`, `error_percentiles[]`. *Floors:* `floor_1d_lookup_nmae` and `floor_sad_nmae`, computed on the same configuration so the comparison is paired rather than aggregate. *Format integrity:* `chgcar_roundtrip_max_abs_diff`, `chgcar_ordering_check` (pass/fail), `chgcar_ordering_trace[]` — the first N values along the x-fastest axis, original and reconstructed, which is what F-A12(b) plots; a pass/fail boolean alone cannot show *how* an ordering bug is wrong. *Cost and outcome:* `inference_seconds` with hardware ref; paired rerun `n_iter_sad`, `n_iter_model`, `wall_time_sad`, `wall_time_model`, `net_time_delta`, `noise_floor_band`. *Field refs* (at `full`): `rho_pred`, `rho_ref`, `rho_sad`, **each per spin channel (total and magnetization)** — F-A3 is not derivable from total-density refs alone.

**(6) Operator probe record** — one per (model, system, basepoint, amplitude, resolution) probe of the learned operator. *Required because F-B1, F-B2, F-B10 and F-B11 report properties of the operator itself rather than of any SCF run, and are therefore not derivable from the run-centric records above.* `model_id`, `system_id`, `basepoint` (the ρ_in probed at — an iteration index or `converged`), `probe_amplitude`, `resolution` (`fft_grid` and `Ecut`, so F-B11 can compare across settings), spin channel. *Measured response:* `G_bins[]` (the pre-registered radial edges), `g_hat[]`, `g_hat_spread[]` (across repeats). *Reference curves on the same bins:* `kerker_kernel[]`, `ldos_kernel[]`, `eps_inv_fd[]` from the §8.6 probe — stored alongside rather than recomputed at plot time, so F-B1's overlays cannot silently drift out of correspondence with the measurement. *Anisotropy (for F-B2):* `g_hat_by_G_vector` over a sampled G-plane, optional. *Spectrum (for F-B10):* `eigenvalues[]` (complex), `preconditioned` (bool), `spectral_radius`, `arnoldi_krylov_dim`, `converged_eigenpairs`.

**8.5 Plotting standards, and what not to plot.**

*Standards (REQUIRED unless marked).* **Provenance stamp** — every figure carries its `run_id`(s), `model_id` and `schema_version` in a footer; *a figure that cannot be traced back to a run is not evidence.* **Regenerability** — every figure is produced by a `run_id`-parameterized notebook from logs alone, with no hidden state (rule I3). **Shared scales** — panels meant to be compared share colour scale and axis limits; the SAD-vs-model error pair of F-A2 is worthless on independent scales. **Colormaps** — signed quantities use a diverging map symmetric about zero; magnitudes use a perceptually uniform map; never rainbow/jet. **Log axes** — residuals, errors and NMAE always. **Thresholds drawn** — every pre-registered floor, tolerance, kill line and θ appears as an explicit line on the figure that evidences it, so pass/fail is visual rather than arithmetic. **Noise floor shown** — every timing figure shades the F-P1 band. **Self-describing fields** — grid, lattice and units travel with every snapshot. **Accessibility (RECOMMENDED)** — colourblind-safe palettes, and `step_source` encoded by both colour and marker.

*What not to plot (REQUIRED — the anti-superfluity rule).* **No figure without a stated question:** the "question it answers" cell in §8.4 is mandatory, and a proposed figure that cannot fill it does not ship. **No raw VASP density published** — clearance permits error and difference fields only (rule I2). **No cross-code raw-density or absolute-energy figure, ever** — §7.8's firewall is encoded here in the figure spec, not left to prose. **Training loss curves are diagnostics, not evidence** — permitted in notebooks, never cited in a gate decision. **No 3-D rendering where a slice or a 1-D profile answers the same question.**

**8.6 Shared machinery: the finite-difference dielectric probe (REQUIRED at Gate-0).** A single matrix-free implementation of the linearized SCF residual application (Gâteaux derivative, in the manner of Das–Gavini) serves three distinct purposes, which is why it is built early rather than deferred: (1) the ground-truth reference curve for **F-B1**; (2) the operator handed to Arnoldi for **F-B10**, the only empirical evidence for **O5**; and (3) §7.2's option-(2) "ideal update" training target (OQ1). Building it once at Gate-0 discharges part of three separate obligations. **REQUIRED:** probe outputs are written as §8.2 record type (6), with the classical reference kernels stored on the same radial bins as the measurement. **Validation before use:** the probe is checked against the analytic Kerker kernel on a system where that kernel is the right answer (Gate-0.5) — an unvalidated probe would corrupt F-B1's reference curve and F-B10's spectrum simultaneously, and both are load-bearing.

**8.7 Honest limits of the inspection suite (REQUIRED framing).**

- **The transfer function is a linearization, not an identity.** The learned map is nonlinear; ĝ(|G|) obtained by impulse probing is amplitude- and basepoint-dependent. **REQUIRED:** probe at a pre-registered set of amplitudes and basepoints (e.g. ρ_in at iterations 1, 5, and converged), report the spread as F-B1's ribbon, and label the figure a linearization. Presenting ĝ as *the* operator would be a plain error in a numerical-analysis venue.
- **F-B9 is only computable where a converged reference exists** — that is, never on the runs that matter most operationally. State the scope whenever it is shown.
- **F-B10's spectrum is per-system and empirical.** It constrains O5; it does not prove it. The distinction is the same one §3.6 draws between the warranty and the local-rate claim.
- **Nothing in this section is a substitute for the certificate.** §7.6's a posteriori bound is the only inspection output that is *proved*; everything else here is demonstrated or descriptive, and is cited that way.

### Section 9 — Risks, Open Questions, and Gate-0

**9.1 Gate-0 (pre-registered, before any model training).** Passed only when all four hold: (1) **Paper-and-pencil lemma** — write the safeguarded-convergence lemma (transplant Zhang–O'Donoghue–Boyd to the DFTK residual setting) and confirm O1–O6 are individually discharged or flagged OPEN. (2) **DFTK pain-case baseline reproduction** — reproduce expected iteration counts for Al-slab / interface / iron with the shipped mixings (Simple, Kerker, Dielectric, LDOS); if baselines can't be reproduced, stop (the harness is wrong). (3) **Headroom probe** — confirm ≥1.5× headroom on at least one pain case. (4) **Monthly arXiv recheck** — confirm the "learned in-loop SCF mixing with a convergence theorem" claim remains unclaimed; log the search. (5) **Instrumentation harness live** — the §8.2 record schema emits a valid run manifest and iterate records for a baseline run; the §8.6 finite-difference dielectric probe is implemented and validated against the analytic Kerker kernel; and **F-P1** (noise floor) and **F-B12** (headroom) are produced. *Rationale:* clause (2) requires reproducing published baseline iteration counts, and that reproduction is not credible evidence unless the record schema already works — an unrecorded baseline cannot be re-examined when a later result contradicts it.

**9.2 Enumerated risks.** **R1 — Nonexpansiveness fails for metallic SCF maps (O5).** *Mitigation:* the safeguard preserves the warranty regardless; restrict the local-rate claim to the proven subclass; use LDOS-preconditioned residuals as the base map. **R2 — FNO instability/drift on density fields (arXiv:2509.00169).** *Mitigation:* small FNO, few modes, discretization-independence training, safeguard backstop. **R3 — Net-time trap for Component A (arXiv:2601.19966).** *Mitigation:* tiny fixed-grid FNO; charge inference cost; kill if net negative. **R4 — NC-vs-PAW mismatch poisons cross-code validation.** *Mitigation:* compare only gap/relative energies/EOS; pre-state tolerances from PseudoDojo deltas. **R5 — DFTK API churn** (interfaces evolve; GPU became stable Dec 2025; frequent releases). *Mitigation:* pin a DFTK version, wrap the interface, re-test on upgrade. **R6 — Theorem scooped.** *Mitigation:* the monthly recheck (Gate-0.4); move quickly on the paper-and-pencil lemma; the certificate + DFTK-native implementation is defensible even if a bare theorem appears elsewhere. **R7 — Observability overhead and FFI marshaling cost.** Instrumentation costs wall-time, and so does the Python→Julia boundary — while Component A's ship gate *is* a wall-time measurement and Component B must report its overhead honestly (§7.6). Left unmanaged, the inspection requirement of §8 would quietly invalidate the gates it exists to serve. *Mitigation:* rule I1 — tiered logging, all gate timings measured at `log_level=off`, reduce-then-marshal, and the tier-to-tier overhead measured once per platform and reported. **R8 — Notebook rot and post-hoc figure selection.** Analysis notebooks drift out of sync with the code that wrote the logs, and an unconstrained figure set invites choosing the flattering ones after the fact. *Mitigation:* rule I3 — the record schema (not the notebook) is the versioned contract, notebooks are `run_id`-parameterized and re-runnable from logs alone, and the §8.3–§8.4 evidence set is pre-registered before training.

**9.3 Initial OPEN-QUESTIONS log (day one).** (1) How exactly to define the "ideal update" target (converged-difference vs finite-difference dielectric probe vs hybrid)? (2) Fixed vs adaptive θ? (3) Do certificates stay *guaranteed* under smearing/fractional occupations? (4) How does DFTK's Anderson history interact *in theory* with a learned preconditioner — does layering Anderson on a learned inverse-Jacobian help or double-count? (5) For which system class is O5 (nonexpansiveness) provable vs only checkable? (6) Which iterations should field snapshots be taken at, and what radial |G| bin edges should be pre-registered? F-B8's diagnostic resolution depends entirely on this choice, and it must be fixed before training to satisfy I3. (7) Over what range of probe amplitudes and basepoints is the impulse-probed ĝ(|G|) stable enough to be a meaningful summary of a *nonlinear* operator (§8.7)? (8) Can the §8.6 finite-difference probe supply F-B1's ground-truth reference at acceptable cost on the larger pain cases, or only on the 2-atom strain cells?

**Each question is assigned an instrument (REQUIRED).** An open question with no way to close it is a wish, not a research plan. (1) → **F-B1**, comparing the transfer function learned under each candidate target against the FD-probed ε†⁻¹; a model trained on converged-density differences should show a visibly different ĝ than one trained on dielectric probes, and if it does not, the two targets are teaching the same thing. (3) → **F-B9**, whose hypothesis-violation colouring marks precisely where smearing breaks the gap assumption. (4) → **F-B6**: `cos_angle(δρ_learned, δρ_anderson)` persistently near 1 *is* double-counting, measured rather than argued. (5) → **F-B10**, per system, against the unit circle. (2), (6), (7) and (8) are calibration choices to be fixed by measurement before training, per rule I3; (7) in particular is answered by the spread of F-B1's own ribbon.

### Section 10 — What to Port from the Old Corpus

**Port (REQUIRED).** *Culture rules:* pre-registered acceptance criteria before training; every residual quoted next to a measured noise floor; baselines implemented before models; negative results reported at full force; one go/no-go gate per target with kill/proceed thresholds written in advance; ship-either-way clauses. *Inspection discipline (new, §8):* the record schema is the versioned contract and analysis code is not; the artifact and figure set is pre-registered before training and every gate decision cites its IDs and `run_id`s; every figure carries a provenance stamp; clearance classes are enforced by the same assertion guards as the POTCAR firewall. These rules exist because "negative results reported at full force" is only cashable when the negative result can be *explained*. *Noise-floor and gate methodology* applied to both components. *Corpus-interface roles (the three):* (1) corpus as **training data** for Component A (converged PBE defect densities); (2) corpus as **ground-truth reference** for cross-code DFTK validation (gap/relative-energy/EOS only, never raw densities/absolute energies); (3) corpus as **workload distribution + pain suite** for Component B (1131 strain geometries re-solved with logging; mag-quarter defect geometries as hard cases). *Specific data files:* the **strain-geometry index** (1179 rows / 1131 distinct shapes, six deformation families, up to 14.85% Green–Lagrange strain, both functionals; equilibrium refs PBE a₀=3.5740 Å B₀=434.2 GPa, HSE06 a₀=3.5465 Å B₀=473.8 GPa) and the **mag-quarter config list** (12–14 ±0.25 μB configs) plus the 33 odd-electron configs. *Known-anomaly registry:* the corrupt Zr HSE06 run (exclude); the 97 PBE/HSE06 paired configs (recorded; HSE06 side unusable in DFTK). *Licensing discipline:* POTCAR/raw-run assertion guards; only numeric aggregates and derived models committed.

**Do NOT port.** All **operator-spec work from the other branch** (superseded by the FNO-on-fixed-grid / discretization-independent designs here). Anything **HSE06-dependent for the DFTK side**: DFTK supports libxc **LDA/GGA/meta-GGA only — no exact exchange, no hybrids**. HSE06 (α=0.27) is out of scope in-platform; any hybrid demonstration is a later port to CP2K/Quantum ESPRESSO and **not part of the core claim**. The 97 HSE06-paired configs feed only PBE-side work and cross-code sanity, not any DFTK hybrid run.

## Recommendations

1. **Execute Gate-0 first (weeks, not months), in this order:** (a) write the paper-and-pencil safeguarded-convergence lemma and the O1–O6 discharge table; (b) stand up the DFTK harness and reproduce published Al-slab/interface/iron baseline iteration counts for SimpleMixing/Kerker/Dielectric/LDOS — *if you cannot reproduce baselines, halt and fix the harness*; (c) run the headroom probe. Do not train any model until Gate-0 passes. **Threshold that changes the plan:** if headroom on all pain cases is < 1.5×, deprioritize Component B in favor of Component A (there is not enough room to beat LDOS).

2. **Build Component A on the tiny-fixed-grid-FNO + SAD-correction design, and measure net wall-time from day one.** Pre-register the two floors (1-D lookup at 0.52–0.65% NMAE; SAD). Report inference cost explicitly and subtract it. **Ship gate:** beat the lookup floor on held-out NMAE **and** show positive net wall-time on real VASP reruns. **Threshold that changes the plan:** if net wall-time is negative after charging inference (the ELECTRAFI failure mode), either shrink the model further or kill Component A and publish the negative result.

3. **For Component B, choose the safeguard-primary (route b) path**: correctness must not depend on the network's Lipschitz constant. Implement via option **B1** (learned mixing + acceptance wrapper falling back to `KerkerMixing`) first; escalate to **B2** (custom safeguarded-Anderson solver) only if you need explicit Powell regularization/restart control. Start training targets with the converged-density difference, then move to finite-difference dielectric probes for the systems where you demonstrate the O3 local-rate improvement.

4. **Treat O5 (nonexpansiveness for metals under smearing) as the paper's central risk.** State precisely the system class for which it is proved vs assumed vs checked. Lean on LDOS-preconditioned residuals as the base map to maximize the chance the base iteration is well-conditioned. Frame the contribution as a **warranty** (O1, unconditional) plus a **local-rate improvement** (O3, on the proven subclass) so a partial O5 result is still a complete, publishable theorem.

5. **Enforce the PAW-vs-NC firewall mechanically** (assertions that block any cross-code comparison of raw densities or absolute energies) and the POTCAR licensing firewall (assertions that block raw-run/POTCAR egress from the private volume). These are correctness and legal requirements, not stylistic preferences.

6. **Keep the monthly arXiv scoop-recheck as a standing task** and move fast on the paper-and-pencil lemma; the unclaimed status of "learned in-loop SCF mixing with a convergence theorem" is the program's whole reason to exist.

7. **Stand up the record schema and the finite-difference dielectric probe during Gate-0, and pre-register the artifact and figure lists before any training.** The schema is cheap and the probe is not, but the probe discharges three obligations with one implementation (F-B1's ground truth, F-B10's Arnoldi operator, and §7.2's option-(2) training target), and O5 has no other instrument. Pre-registration is what makes the figure set evidence rather than illustration. **Threshold that changes the plan:** if instrumented runs cannot be brought within a small, measured overhead of `log_level=off` runs, fix the logging path before trusting any timing result — Component A's entire gate is a wall-time measurement (R7).

## Caveats

- **DFTK has no hybrids.** libxc LDA/GGA/meta-GGA only; no exact exchange. HSE06 is out of scope in-platform. Any hybrid claim requires a later port to CP2K/Quantum ESPRESSO and is not part of the core theorem.
- **PAW vs NC densities are not comparable.** VASP (PAW) and DFTK (norm-conserving) must be compared only on pseudopotential-insensitive observables (band gaps, relative energies, EOS parameters). The magnitude of the carbon/diamond PAW-vs-NC delta should be taken from PseudoDojo benchmarks and used to set validation tolerances; I was unable to pin an exact published carbon delta within budget — **verify before setting the cross-code tolerance.**
- **The net-time trap is real and quantified.** ChargE3Net's step reductions do not translate to net wall-time on Materials Project once inference cost is charged (ELECTRAFI, arXiv:2601.19966). Component A lives or dies on measured net wall-time, not step counts.

- **DFTK API churn.** GPU support became stable December 2025 and releases are frequent; some documentation pages still carry older "preliminary" GPU wording. Pin a DFTK version and re-test the mixing/callback/solver interfaces on every upgrade.
- **Instrumentation is not free, and neither is the Python→Julia boundary.** Both inflate wall-time, and Component A's ship gate *is* a wall-time measurement (§6.6) while Component B must report overhead honestly (§7.6). Unless gate timings are measured at `log_level=off` and the tier-to-tier deltas reported (rule I1), the inspection machinery of §8 would quietly invalidate the gates it exists to serve. It is amplitude- and basepoint-dependent; it must be probed at a pre-registered set of both, shown with its spread, and labelled as a linearization.
